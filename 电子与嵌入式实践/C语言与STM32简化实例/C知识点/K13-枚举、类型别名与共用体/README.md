# K13 枚举、类型别名与共用体

这一组笔记处理三个经常一起出现在 C 嵌入式代码里的工具：

- [枚举：给状态和配置项命名](枚举：给一组整数常量起名字.md)
- [typedef：给已有类型起一个可读的别名](typedef：四种常见形态与库里的别名网.md)
- [共用体：让多种解释共享一块存储](共用体：一块内存的多种读法.md)

推荐顺序是“枚举命名 → typedef 声明 → union 存储”。先看清名字和值的关系，再处理复杂声明，最后才讨论重叠存储和字节序。

## 读这组笔记时的边界

- C 语言枚举的兼容整数类型由实现决定；不要把“通常像 int”写成跨工具链保证。
- typedef 只建立别名，不创建新对象，也不改变原类型的内存布局。
- union 的成员共享存储；跨成员读取的结果与可移植性必须结合语言规则、编译器和目标平台判断。
- STM32 标准外设库中的类型名、枚举值和寄存器编码必须以对应版本头文件、芯片参考手册和工程配置为准。
