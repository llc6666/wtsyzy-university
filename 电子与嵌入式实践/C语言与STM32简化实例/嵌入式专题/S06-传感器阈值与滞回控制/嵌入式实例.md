# S06 嵌入式实例

## 一、PC 侧：已验证

文件：[sensor-hysteresis-demo.c](sensor-hysteresis-demo.c)，输出见 [README](README.md)。

验证的是：同一读数序列下三种控制策略的翻转次数（6 / 2 / 2）、滞回带内维持、去抖延迟 N 拍生效。

## 二、工程原型对照（传感器示例工程）

该工程的完整控制逻辑只有一行（DO 直通），初始化部分是标准 SPL：

```c
void sensor_control_init(void){
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);   /* 开 GPIOB 时钟 */

    GPIO_InitTypeDef GPIO_Initstructure;
    GPIO_Initstructure.GPIO_Pin   = GPIO_Pin_12;            /* PB12 接 LED */
    GPIO_Initstructure.GPIO_Mode  = GPIO_Mode_Out_PP;       /* 推挽输出 */
    GPIO_Initstructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_Initstructure);

    GPIO_Initstructure.GPIO_Pin  = GPIO_Pin_13;              /* PB13 接光敏 DO */
    GPIO_Initstructure.GPIO_Mode = GPIO_Mode_IPU;           /* 上拉输入 */
    GPIO_Init(GPIOB, &GPIO_Initstructure);

    GPIO_SetBits(GPIOB, GPIO_Pin_12 | GPIO_Pin_13);
}

void 本地传感器工程原型(void){
    GPIO_WriteBit(GPIOB, GPIO_Pin_12, GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_13));
}
```

读输入是 `GPIO_ReadInputDataBit`（返回 0/1），写输出是 `GPIO_WriteBit`——没有软件阈值的位置：阈值焊在模块的电位器上。

## 三、升级到 AO + ADC 需要加什么

光敏模块的 AO 引脚接 ADC 输入通道后，读数变成 0~4095 的数值（12 位），软件阈值才有意义。SPL 的 ADC1 单次读数骨架（示意，未上板验证）：

```c
void adc1_init(void)
{
    ADC_InitTypeDef ADC_InitStructure;
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE);

    ADC_InitStructure.ADC_Mode = ADC_Mode_Independent;
    ADC_InitStructure.ADC_ScanConvMode = DISABLE;       /* 单通道 */
    ADC_InitStructure.ADC_ContinuousConvMode = DISABLE;  /* 单次转换 */
    ADC_InitStructure.ADC_DataAlign = ADC_DataAlign_Right;
    ADC_InitStructure.ADC_ExternalTrigConv = ADC_ExternalTrigConv_None;
    ADC_Init(ADC1, &ADC_InitStructure);
    ADC_Cmd(ADC1, ENABLE);

    ADC_ResetCalibration(ADC1);
    while (ADC_GetResetCalibrationStatus(ADC1));
    ADC_StartCalibration(ADC1);
    while (ADC_GetCalibrationStatus(ADC1));             /* 校准必须等完 */
}

uint16_t adc1_read(uint8_t channel)
{
    ADC_RegularChannelConfig(ADC1, channel, 1, ADC_SampleTime_55Cycles5);
    ADC_SoftwareStartConvCmd(ADC1, ENABLE);
    while (!ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC));     /* 等转换完成 */
    return ADC_GetConversionValue(ADC1);
}
```

上面的 ADC 片段仅说明调用顺序，不是完整初始化工程；GPIO 模拟输入、ADC 时钟分频、通道数、采样时间、电压范围与等待超时仍需补齐。拿到数值后，可将本 demo 的滞回与去抖逻辑移植到业务层，重新核对采样周期和输出极性。

## 四、光敏模块的 DO 与 AO 差别

| 引脚 | 输出 | 阈值由谁定 | 软件能做什么 |
| --- | --- | --- | --- |
| DO（数字） | 0/1 电平 | 模块电位器（硬件比较器） | 只能读、直通 |
| AO（模拟） | 电压 → ADC 读数 | 软件 | 阈值/滞回/去抖/滤波全可编程 |

接线细节与传感器原理见正式笔记：`本地嵌入式知识库/02-STM32\04-板卡与外设\带DO的光敏电阻传感器：原理、接线与STM32读取.md`。

## 五、蜂鸣器报警：同一套逻辑换执行器

`传感器示例工程/Hardware/bark.c` 目前为空文件。填它时只需要：把 demo 的「LED 开/关」换成「蜂鸣器响/停」，控制逻辑一行不改。报警类应用建议直接用**滞回 + 去抖**档（宁可晚 300ms 响，不可误报）。

## 六、上板前要核对的

- 光敏模块接的是 DO 还是 AO（本 demo 对应 AO）
- ADC 通道号与实际引脚一致（F103C8T6 的 ADC 通道见数据手册引脚定义表）
- 采样周期与去抖 N 的乘积 = 真实响应延迟，按应用定
- 滞回带宽度按传感器噪声幅度定：带比噪声窄等于没带

## 七、把本专题带回 PC 的做法

阈值类控制的 PC 验证法：**预设读数序列 + 逐行打印决策**。序列要故意包含：缓慢穿越阈值、边界 ±2 抖动、单点尖峰、反向穿越。这四类输入在 PC 上 20 行数组全覆盖；在板子上等真实光照变化，很难系统试全。
