# 队列：先进先出与双指针

## 一句话结论

队列是先进先出（FIFO）的线性结构：队尾进、队头出。链表实现需要**两个指针**（head 出队端、tail 入队端）。两个关键边界：空队入队必须特判（head 和 tail 都指向新节点）；出队删空后 tail 必须置 NULL。

## 它解决什么问题

排队模型：先来先服务。操作系统任务调度、打印机任务缓冲、网络数据包排队、树的广度优先遍历，底层都是队列。它和栈（后进先出）是线性结构的两个极端。

## 工作机制

```
入队端（队尾）            出队端（队头）
  新来的 → [C] → [B] → [A] → 先走的
               tail        head
```

**enqueue（入队）**：新节点接到队尾，分两种情况：

```cpp
void Queue::enqueue(int d) {
    Node* p = new Node(d);
    if (head == NULL && tail == NULL) {
        head = p;          // 空队特判：没有尾巴可接
    } else {
        tail->next = p;    // 非空：接在旧尾巴后面
    }
    tail = p;              // 两种情况都要更新 tail
}
```

**dequeue（出队）**：队头离开，注意删空后的处理：

```cpp
int Queue::dequeue() {
    if (head == NULL) return -1;   // 调用时本来就空 → 返回 -1
    Node* p = head;
    int d = head->data;            // 先拿值
    head = head->next;             // 换头
    delete p;                      // 删旧头
    if (head == NULL) {
        tail = NULL;               // 删空了：tail 必须清醒，否则悬空
    }
    return d;                      // 统一返回记下的值
}
```

**front**：返回 head->data，不删。**isEmpty**：head == NULL。

## 对比栈

| | 栈 | 队列 |
| --- | --- | --- |
| 顺序 | 后进先出（LIFO） | 先进先出（FIFO） |
| 操作端 | 只在一头（栈顶） | 两头（队尾进、队头出） |
| 指针数 | 一个（top） | 两个（head + tail） |
| 类比 | 叠盘子 | 排队打饭 |

## 常见错误与边界

1. **空队入队不特判**：`tail->next` 解引用 NULL，崩。
2. **删空后 tail 不置 NULL**（最阴险）：tail 悬空指向已删节点，下次入队时空队判断 `head==NULL && tail==NULL` 失灵，head 永远不更新，新节点全部丢失。
3. **`==` 写成 `=`**：`tail == NULL` 是比较不是赋值，看似修了实际没修，潜伏雷。
4. **删空后 return -1**：删掉的是有效元素（d 已取出），必须返回 d。-1 只在"调用时本来就空"返回。两种空要分清。

## 使用规则

- 空队判断用 `head == NULL && tail == NULL`，两者必须一致（删空时 tail 要跟上）。
- 出队先取值、再换头、再删、最后检查删空。
- "调用时空"返回 -1，"删空"返回有效值。
- 空队入队、出空再入队是必测用例。
