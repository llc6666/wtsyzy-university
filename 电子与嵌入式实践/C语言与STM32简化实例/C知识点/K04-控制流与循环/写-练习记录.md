## leap

- 签名：`bool leap_year(int year)`
- 题面要点：能被 4 整除是闰年；但能被 100 整除且不能被 400 整除的不是；能被 400 整除的是

### 验收标准（用例表 + 五类边界）

| 输入 | 期望 |
| --- | --- |
| `1996` | 闰年（被 4 整除，不被 100 整除） |
| `1900` | 不是（被 100 整除，不被 400 整除） |
| `2000` | 是（被 400 整除） |
| `2023` | 不是 |
| `2024` | 是 |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `year = 0` | 按规则判定（0 能被 400 整除，多数实现判为闰年；需明确自己的约定） |
| 最小 | `year = 1` | 不是闰年 |
| 最大 | `INT_MAX` 附近的年份 | 取模运算不溢出 |
| 相等 | 连续两个闰年（2020、2024） | 都判为闰年 |
| 非法 | 负数年份 | 题面未定义；不得崩溃 |

- 不变量：返回值只可能是 true/false；规则的三层顺序不能颠倒（400 必须在 100 之前判断）

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**：这一题没有复杂度问题，「暴力与否」的差别在于是否把三层规则全列出来
3. **哪里最容易错**：只判 4；或把 100 的判断写在 400 前面

## raindrops

- 签名：`void convert(char result[], int drops)`
- 题面要点：3→`Pling`、5→`Plang`、7→`Plong`，顺序固定；都不是则输出数字字符串
- 调用方提供 `result` 数组，**函数内部不分配内存**

### 验收标准（用例表 + 五类边界）

| 输入 | 期望 |
| --- | --- |
| `28` | `Plong` |
| `30` | `PlingPlang` |
| `34` | `34` |
| `105` | `PlingPlangPlong` |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `drops = 0` | 0 能被 3、5、7 都整除 → `PlingPlangPlong`（需与自己的实现约定一致） |
| 最小 | `drops = 1` | `1` |
| 最大 | 接近 `INT_MAX` 的数 | 取模与 `snprintf` 都不出错 |
| 相等 | 同一个数连续调用两次 | 结果相同（数组必须每次先清空） |
| 非法 | 负数 | 取模结果依编译器而定；建议先取绝对值或明确约定 |

- 不变量：三个判断的顺序固定为 3、5、7；`result` 以 `\0` 结尾；函数不修改 `drops`

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**
3. **哪里最容易错**：用 `else if` 链（30 会只输出 Pling）；第二次调用时没清空数组，结果被追加
