# 职业方向的能力组合

## 结论

职业方向应按重复出现的任务、能力组合和进入门槛来判断，而不是按专业标签、行业口号或单个成功案例判断。

## 三类能力

- **基础能力**：分析、表达、编程、数学、协作等可迁移能力。
- **场景能力**：在某类任务或行业环境中解决问题的能力。
- **证明材料**：项目、课程、实习、作品与外部反馈形成的证据。

专业名称只是起点。真正的匹配需要同时看任务要求、能力缺口、进入路径和自身是否愿意长期承担这类工作。

## 判断步骤

1. 先明确具体岗位或任务场景，避免从抽象行业词开始。
2. 收集多个岗位说明、项目样本或访谈，提炼反复出现的能力。
3. 划分必须具备、可迁移补足和短期难以补足的能力。
4. 用课程任务或小项目验证兴趣和完成能力。
5. 把能力映射到学习计划、作品和反馈上。
6. 定期复查方向，保留调整路径。

## 边界

行业结构和岗位要求会变化。个人能力组合不能保证结果，还会受到学历、地区、经验和竞争影响。网络中的收入或成功案例缺少完整样本时，不能用来直接外推。
