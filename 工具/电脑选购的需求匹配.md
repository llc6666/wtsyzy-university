# 电脑选购的需求匹配

## 结论

先定义未来一到两年的真实任务、软件约束和使用周期，再比较硬件。型号和参数只有在任务上下文中才有意义。

## 四层需求

| 层次 | 要核验的内容 |
| --- | --- |
| 任务 | 编程、建模、设计、剪辑、办公或游戏等实际负荷 |
| 软件 | 操作系统、专业软件、兼容性和授权要求 |
| 生命周期 | 携带、维修、升级、散热、备份和预计使用年限 |
| 预算 | 设备、配件、存储、维护与替代方案的总成本 |

任务决定最低性能，生命周期决定可靠性，预算决定取舍。

## 购买前的动作

1. 写下最重的三类任务，不能只写“学习”和“娱乐”。
2. 查询每项任务的软件官方要求与系统兼容性。
3. 分成必须满足、最好具备和可放弃三档。
4. 估算携带频率、维修风险与外接设备需求。
5. 购买后建立备份、更新和问题记录习惯。

## 边界

本页不提供具体型号。硬件价格、软件版本和专业要求都会变化，购买前必须重新核验。预算受限时，实验室、云资源或外接设备也可能改变最优方案。
