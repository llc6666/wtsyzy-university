# 滑动平均滤波：队列的 DSP 应用

## 一句话结论

滑动平均滤波用长度为 N 的窗口内最近 N 个采样的平均值代替当前值，抹平随机噪声。窗口滑动本质是队列：新采样入队，窗口满了队头出队。这是嵌入式 ADC 去噪最基础的算法。

## 它解决什么问题

ADC 采样有随机噪声：真实值 22，采样可能是 20、22、21、24、23，单值不可信。噪声是随机抖动的，平均值让它们互相抵消，结果稳定在真实值附近。滑动平均是"用最近的 N 个值投票"。

## 工作机制

```
数据流：20 22 21 24 23 25 26
        ┌─────────────┐
        │20 22 21 24 23│  窗口①：平均22
        └─────────────┘
           ┌─────────────┐
           │22 21 24 23 25│  窗口②：20被挤出，平均23
           └─────────────┘
```

窗口 ↔ 队列的对应：

| 窗口概念 | 队列操作 |
| --- | --- |
| 新采样进来 | enqueue |
| 窗口满了再来新的 | 先 dequeue 再 enqueue |
| 当前窗口长度 | size() |

核心循环（每步四动作）：

```cpp
// 读一个采样 x
// enqueue(x)
// 如果 size() > N：dequeue()
// 遍历求和 sum / size() → 输出
```

## 最小示例

```cpp
// 窗口 N=5，输入 7 个采样
// 输出每步平均：20 21 21 21 22 23 23
```

## 常见错误与边界

1. **输出位置**：平均值要在循环内每步输出，不是循环结束后输出一次。
2. **sum() 忘 return**：int 函数必须交回值，否则返回垃圾值。
3. **tail 无条件置空**：dequeue 只在删空（head 变 NULL）时置 tail。
4. **窗口未满**：前 N-1 步窗口不满，按实际个数平均（÷size），不是 ÷N。
5. **计数器未初始化**：`int k;` 必须 `int k = 0;`。

## 使用规则

- 每步：入队 → 超长出队 → 求和 → 输出平均，顺序固定。
- 平均值用整数除法时注意截断（DSP 中常用定点数避免浮点开销）。
- 窗口长度是滤波器参数：窗口越大越平滑、响应越慢；越小越灵敏、去噪越弱。
