# 旋转编码器：A/B 相位与 STM32 计数

## 先回答问题

增量式旋转编码器的 A、B 两路信号相位不同。一路的边沿告诉程序“发生了变化”，另一条路在相近时刻的电平或边沿顺序提供方向线索。读取 B 不是重复读取 A，而是在读取正交信号的相位关系。

本页是资料核对与实验设计，不宣称已经在某块开发板或某个编码器上下载、测量并验证。具体电平、接线、有效边沿和加减方向必须按器件与实测结果确认。

## 输入和角色

常见模块会把引脚标为 A/CLK、B/DT 和 SW：

| 信号 | 用途 | 能否单独判断旋转方向 |
| --- | --- | --- |
| A/CLK | 旋转脉冲或相位 A | 只能知道变化事件，不能可靠知道方向 |
| B/DT | 相位 B | 与 A 配合判断方向 |
| SW | 按压开关 | 与旋转方向无关 |

不要把 SW 当作 B 相。接线前先画一张板卡事实卡，写清芯片、输入电压、上拉/下拉、引脚复用、触发边沿和公共地。

## 用状态顺序理解方向

把 A、B 看成两个二进制位，四个稳定状态可以按两个相反方向循环：

```text
方向一：00 → 01 → 11 → 10 → 00
方向二：00 → 10 → 11 → 01 → 00
```

实际模块的“顺时针”对应哪一个方向，取决于 A/B 接线和机械安装。不要把“B 为高就加”当成通用规律。更稳妥的定义是：记录上一状态和当前状态，只接受合法的单步状态变化，再按查表结果加一或减一；同时对 `00→11` 这类一次跳过两位的变化设为无效或错误，避免把抖动误算成一步。

如果只使用 EXTI：

1. 选择 A 的上升沿、下降沿或双边沿作为事件。
2. 在中断中快速读取 B，按已确认的接线约定更新计数。
3. 处理机械抖动，避免在一次 detent 附近产生多次计数。
4. 不在 ISR 中延时、刷新屏幕或打印长日志。

这种方案适合低速入门实验，但每个边沿都占用 CPU，抖动和高速丢边沿必须单独测试。

## STM32 定时器编码器接口

STM32F1 定时器可以把 A、B 接到 TI1、TI2，使用编码器接口模式，让硬件依据两路信号关系自动递增或递减计数器。ST 的 RM0008 给出了编码器信号与计数方向的关系；ST 的 AN4013 说明了 X2、X4 模式和定时器输入滤波：[RM0008](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)、[AN4013](https://www.st.com/resource/en/application_note/an4013-stm32-crossseries-timer-overview-stmicroelectronics.pdf)。

| 方案 | 方向由谁判断 | 主要验收对象 |
| --- | --- | --- |
| EXTI + GPIO | 软件读取另一相或状态表 | ISR 延迟、抖动、计数溢出 |
| TIM 编码器接口 | 定时器硬件 | TI1/TI2 映射、极性、滤波、CNT 方向 |

X2 与 X4 的计数边沿不同，不能只凭“分辨率更高”修改配置。先确认芯片定时器是否支持编码器接口，再核对 TI1/TI2 映射、输入极性、滤波参数、计数器宽度和溢出处理。

## 最小实验记录

每轮只改一个变量，并留下以下记录：

| 项目 | 要记录的内容 |
| --- | --- |
| 资料 | 芯片型号、参考手册章节、开发板原理图版本 |
| 接线 | A、B、SW、供电、GND、上拉/下拉和实际电平 |
| 配置 | EXTI 或 TIM、触发边沿、极性、滤波、X2/X4 |
| 观察 | 顺时针/逆时针各转固定格数，记录 CNT 或软件计数变化 |
| 边界 | 快速转动、反向切换、停在抖动位置、计数溢出 |
| 结论 | 资料说明、板上实测、推断和待核验项分栏写 |

放行条件：低速正反转方向正确；固定格数重复多次的计数误差已记录；反向切换不会持续累加错误方向；高速、抖动和溢出没有被低速结果替代。没有这些记录，只能写“代码已编译”或“配置已生成”，不能写“编码器实验完成”。

## 常见错误

1. 只接 A 相却要求方向判断：信息不足。
2. 把当前单路脉冲工程直接当成正交编码器：两者输入模型不同。
3. 只用“B 高加、B 低减”而不记录边沿和接线：换线后方向可能反转。
4. 在 ISR 中调用长延时或显示函数：增加阻塞，可能丢失后续边沿。
5. 只在低速手拧时测试：不能推出高速抗抖动能力。
6. 把一次方向正确写成计数器长期可靠：还需检查溢出、滤波、断电和重新归零策略。
