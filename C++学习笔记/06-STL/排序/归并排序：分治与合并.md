# 归并排序

步骤：

1. 把区间从中点分成左右两段。
2. 递归排序左右两段。
3. 用两个指针把两个有序区间合并。

```cpp
void merge_sort(std::vector<int>& a,
                std::vector<int>& temp,
                int left,
                int right) {
    if (left >= right) {
        return;
    }

    int mid = left + (right - left) / 2;
    merge_sort(a, temp, left, mid);
    merge_sort(a, temp, mid + 1, right);

    int i = left;
    int j = mid + 1;
    int k = left;

    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) {
            temp[k++] = a[i++];
        } else {
            temp[k++] = a[j++];
        }
    }

    while (i <= mid) {
        temp[k++] = a[i++];
    }
    while (j <= right) {
        temp[k++] = a[j++];
    }

    for (int p = left; p <= right; ++p) {
        a[p] = temp[p];
    }
}
```

使用 `<=` 优先取左边元素，是保持稳定性的关键之一。需要额外数组，空间复杂度为 `O(n)`。
