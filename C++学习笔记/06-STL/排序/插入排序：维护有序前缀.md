# 插入排序

把左侧看作已经有序，每次取出一个新元素，将比它大的元素向右移动，再插入空位。

```cpp
void insertion_sort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int value = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > value) {
            a[j + 1] = a[j];
            --j;
        }

        a[j + 1] = value;
    }
}
```

它对接近有序的数据很有效，最好情况可以达到 `O(n)`；稳定、原地，适合小规模或作为复杂排序的子过程。
