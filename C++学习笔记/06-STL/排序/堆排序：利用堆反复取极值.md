# 堆排序：利用堆反复取极值

## 什么时候用

需要理解堆如何在数组上维护最大值，或需要一个确定 `O(n log n)`、额外空间 `O(1)` 的原地排序思路时。若需求是不断插入再取当前最大值，应使用 `std::priority_queue`，不应每次重新做堆排序。

## 机制

最大堆满足：每个父节点不小于子节点，因此 `a[0]` 是当前最大值。每轮把 `a[0]` 与未排序区间的最后一个元素交换，最大值就固定在末尾；再对缩小后的区间恢复堆。`std::make_heap` 负责建堆，`std::sort_heap` 重复完成“交换加恢复”的过程。

## 最小可运行示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

void heap_sort(std::vector<int>& a) {
    std::make_heap(a.begin(), a.end());  // a[0] 变成最大值
    std::sort_heap(a.begin(), a.end());  // 升序结果
}

int main() {
    std::vector<int> a = {4, 10, 3, 5, 1};
    heap_sort(a);
    for (int x : a) std::cout << x << ' ';
}
```

预期输出：

```text
1 3 4 5 10
```

## 如何验证

在 `make_heap` 后、`sort_heap` 前临时输出 `a[0]`，本例应输出 `10`。然后删除 `sort_heap`，你会发现数组只满足堆性质，不是完整升序，这能区分“建堆”和“排序完成”。

## 复杂度与边界

- 建堆 `O(n)`，反复取极值总计 `O(n log n)`。
- 额外空间 `O(1)`，通常不稳定。
- `sort_heap` 的前提是区间已经被同一比较器建成堆；直接对普通数组调用结果无意义。
- 想自定义降序或排序结构体时，`make_heap` 和 `sort_heap` 必须传入同一个比较器。
