# 大学学习与决策方法

这是一个面向本科生的公开知识库，收录可迁移的学习、知识库构建、课程规划、项目选择与职业判断方法。

每篇方法页都以可检查的产物结束：表格、卡片、模板、项目说明、维护报告或测试记录。若读完无法完成一个具体动作，页面仍需要继续改写。

它不提供任何学校的具体制度、课程名单、选课技巧、个人经历样本或实时信息。具体学校的培养方案、选课通知、竞赛规则、价格和岗位要求，应回到官方来源核验。

## 先从这里开始

1. 想建自己的知识库：从 [方法论](方法论/README.md) 的“从零搭建”开始。
2. 手头有资料却很乱：使用 [资料入库与来源卡片](方法论/知识库构建/资料入库与来源卡片.md)。
3. 面临选课、项目或方向选择：写一张 [可复查的决策记录](方法论/决策与项目/可复查的决策记录.md)。
4. 准备公开笔记或作品：完成 [脱敏与发布检查](方法论/公开发布/公开知识库的脱敏与发布检查.md)。
5. 想让 Agent 协助长期工作：先写 [任务契约](方法论/Agent使用/把需求写成可执行任务.md)，再分级授予工具权限。
6. 想规划职业方向：从 [职业规划方法论](方法论/职业规划/README.md) 的岗位样本与能力资产开始。
7. 想清理或重写旧笔记：先执行 [笔记质量门槛与审计流程](方法论/知识库构建/笔记质量门槛与审计流程.md)。

## 使用边界

- 内容是决策和学习框架，不构成学校政策、职业承诺、购买建议或医疗、法律、财务建议。
- 当内容与当前官方文件冲突时，以官方文件为准。
- 任何涉及个人信息、账号、成绩、学校内部流程、未公开材料和第三方原文，均不应提交到本仓库。

公开编译范围和脱敏规则见 [公开边界与脱敏说明](公开边界与脱敏说明.md)。
