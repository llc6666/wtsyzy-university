# 字典序最小的定长子序列：删除额度与栈

## 适用场景与输入契约

输入一个只含 ASCII 小写英文字母的字符串 s，长度为 N。保持字符相对顺序，从中取出恰好 K 个字符，要求结果的字典序最小，且 `0 ≤ K ≤ N`。

子序列可以跳过位置。例如从 `dbca` 选出 `ba`，取的是原位置 2、4，不要求连续。要求连续子串时，本页算法不适用。

字典序先看第一个不同的字符；本题候选长度相同，不需要处理“一个候选是另一个的前缀”的长度比较。[C++ 标准草案：字典序比较](https://eel.is/c++draft/alg.lex.comparison)

准备支持 C++17 的编译器、[完整实现与穷举校验](../代码示例/字典序最小定长子序列.cpp)。命令行输入格式是 `字符串 K`；空字符串和 K=0 的边界在函数自测中验证。

## 1. 把选 K 个改成删 N−K 个

定义删除额度 `remaining = N - K`。从左到右扫描新字符 c，用字符串 `answer` 模拟栈。

每次执行：

1. 栈非空、还有删除额度、且栈顶大于 c 时，删除栈顶并消耗一个额度。
2. 重复第 1 步，直到任一条件不成立。
3. 把 c 加入栈。
4. 扫描完后，如果还多于 K 个字符，删除末尾，截到 K。

核心循环：

```cpp
std::size_t remaining = s.size() - k;
std::string answer;
answer.reserve(s.size());
for (char c : s) {
    while (!answer.empty() && remaining > 0 && answer.back() > c) {
        answer.pop_back();
        --remaining;
    }
    answer.push_back(c);
}
answer.resize(k);
```

先检查 `k <= s.size()`，再做无符号减法。`empty()` 必须在 `back()` 前；`&&` 的从左到右短路判断使空栈时不会读取栈顶。

## 2. 手工走完一个例子

`s = dbca，K = 2`，初始可删 2 个：

| 读入 | 动作 | 栈 | 剩余额度 |
| --- | --- | --- | --- |
| d | 入栈 | d | 2 |
| b | d 大于 b，删 d；加入 b | b | 1 |
| c | b 小于 c，加入 c | bc | 1 |
| a | 删 c；额度用完，加入 a | ba | 0 |

结果是 `ba`。最后的 b 大于 a，但不能再删 b，否则只剩一个字符，凑不够 K。

这揭示一个重要边界：算法有“遇到较小值就弹出较大栈顶”的操作，最终结果却不保证单调。相等字符也不会被删除，所以不能把栈写成“始终严格递增”。在删除额度仍大于 0 时，已维护的栈是非递减的；额度用完之后，新字符可能使它下降。

## 3. 为什么这个贪心选择成立

可以先用一个慢但直观的构造检查思路：当前还要选 r 个字符，从位置 start 开始，下一字符只能从闭区间 `[start, N-r]` 选。再晚就没有足够字符凑满 r。选窗口中最小字符，相等时选最靠左的那个，再向右继续。

这个选择正确，因为：

1. 任一合法结果的下一字符都来自该窗口。
2. 窗口最小字符能使当前首个比较位置最小；后缀再好也不能弥补这个位置更大。
3. 相等时保留最靠左的字符，后续可选位置更多，不会损失可行答案。

栈是这项选择的线性实现：当后来的 c 更小且还能删除时，弹掉尾部的较大字符，让 c 向前；遇到小于或等于 c 的字符时停下，保留已经更优的前缀。删除额度限制保证不会为了局部更小而丢掉凑满 K 的能力。

扫描中删除了 d 个，则最后长度为 `N-d`，剩余额度为 `N-K-d`，两者相差恰好 K。若还有额度，栈保持非递减；从末尾删除不会把前面更小的字符换成后面更大的字符。因此最后截到 K 完成剩余删除。

完整示例中的暴力参考实现枚举所有长度 K 的子序列、逐一比较最小值，与以上推理独立。有限穷举用于检验实现，不能替代适用于任意 N 的正确性论证。

## 4. 用反例检查三种常见错误

| 错误写法 | 反例 | 错在哪里 |
| --- | --- | --- |
| 把 `while` 写成只弹一次的 `if` | `bca，K=1`，正确是 a | 读 a 时要先删 c 再删 b；只删 c 后截尾会得到 b |
| 相等也弹，即 `>=` | `aab，K=2`，正确是 aa | 删掉第一个 a 没改善字典序，却耗掉额度，可能得到 ab |
| 只弹栈顶，最后不截到 K | `abc，K=2`，正确是 ab | 全程没有逆序，仍必须从末尾删一个 |

另测 `cba，K=2 → ba`，它直接反驳“最终答案一定递增”。不要为了满足错误的单调描述继续弹栈。

```powershell

'bca 1' | & "$env:TEMP\smallest-subsequence.exe"
'abc 2' | & "$env:TEMP\smallest-subsequence.exe"
```

`g++` 需已加入 PATH。后三次输出依次为 `ba、a、ab`。

自测做四项独立检查：

1. 枚举字母表 `{a,b,c}`、长度 0 到 8 的所有字符串，以及每个合法 K，与暴力枚举子序列的最小值比较，共 83,653 组。
2. 对这些结果另查长度为 K、结果确为原串子序列。
3. 对 200,000 个同一字符和长度 200,000 的降序分段字符串运行边界测试。
4. 拒绝 K>N 以及超出小写英文字母契约的输入。

## 6. 复杂度、交付物与迁移边界

每个字符入栈一次，最多弹出一次，总时间 `O(N)`。示例为栈预留 N 个字符，额外空间 `O(N)`；不要因为最后只输出 K 个，就把这份实现的空间写成 `O(K)`。
