# 嵌入式、硬件与计算岗位公开快照

## 阅读方式

这是一组 2026-10-22 采集的公开岗位与薪资样本，覆盖嵌入式软件、硬件开发、前沿部署、软件测试、非标测试装备和 HPC 解决方案。它用于拆岗位任务和能力要求，不代表当前仍在招聘，也不代表行业平均水平。

薪资来自招聘页面、公开校招信息、招聘平台汇总或行业文章，口径可能是月薪、年薪、总包或若干薪。保留原口径，不把不同口径直接求平均。页面可能失效，投递前重新打开原始链接。

## 2. 从岗位动词倒推学习顺序

### 嵌入式软件

1. C 语言：指针、内存、数组传参、结构体和多文件组织。
2. STM32 裸机：GPIO、串口、定时器、I2C/SPI、DMA。
3. RTOS：任务、队列、信号量、互斥锁和调度边界。
4. 嵌入式 Linux：交叉编译、Bootloader、设备树、字符设备。
5. 综合项目：采集、处理、显示和通信形成一条可交付链路。

### 板级硬件

1. 电路、模电、数电和电源基础。
2. 一款 EDA 工具的原理图、PCB、Gerber 和版本管理。
3. STM32 最小系统板的原理图到调试闭环。
4. 电源、SI/PI、EMC 和高速接口。
5. 通过项目或实习积累器件选型、故障定位和量产导入证据。

### FDE

1. 扎实的一门编程语言和 Linux。
2. 网络、容器和接口集成。
3. AI 应用栈或具体行业业务流程。
4. 用需求澄清、PoC、部署和交付文档证明解决问题能力。
5. 单独记录出差、驻场和客户沟通要求，不能只看技术关键词。

### 测试与测控

1. 测试理论、用例设计和缺陷管理。
2. Python、接口测试、自动化框架和 CI/CD。
3. Linux、SQL、网络协议或硬件仪器。
4. 用测试报告、缺陷闭环和可复现脚本形成证据。
5. 测试装备方向再补 PCB、LabVIEW/TestStand 和环境试验知识。

### HPC

1. Linux 与 C/C++。
2. 计算机体系结构和内存/并行模型。
3. OpenMP/MPI，再到 CUDA 或其他 GPU 平台。
4. Slurm、perf、Nsight 和性能报告。
5. 在科学计算或 AI4S 项目中形成应用迁移与优化证据。

## 3. 读研与本科入口怎么读

不要把“硕士优先”改写成“本科不能做”。应拆成三类：

- 本科可直接投：嵌入式应用、板级硬件、软件测试等一部分岗位。
- 硕士明显增加选择：高端驱动/BSP、核心硬件、院所研发、非标测试装备和 HPC。
- 岗位硬门槛需逐条核对：学历、专业、经验、城市、是否接受应届、是否长期出差。

这张表只能帮助安排学习投入，不能替代某个具体岗位的投递判断。

## 4. 用样本做一个月的能力审计

每周选一个岗位样本，完成以下记录：

1. 抄录岗位动词：开发、调试、集成、分析、优化、交付。
2. 把动词转换为产物：代码、原理图、测试报告、性能报告、部署文档。
3. 给每个产物列出最小能力：语言、工具、协议、数据结构或仪器。
4. 选择一个低成本练习，只覆盖一个最大缺口。
5. 保存输入、过程、输出和证据边界。
6. 下次查看同类岗位，记录哪些要求重复出现，哪些只是单个公司的特例。
