# 快速排序：分区与递归

## 什么时候用

用于理解分区、递归边界和基准值的作用。业务与竞赛中的一般排序使用 `std::sort`，它已处理许多工程细节。

## 机制

选择一个 `pivot` 后，双指针从区间两侧向中间移动：左指针停在不该在左侧的值，右指针停在不该在右侧的值，交换两者。循环结束后，区间被分成两个更小区间，递归继续处理。

这里使用 Hoare 分区：递归区间是 `[left, j]` 与 `[j+1, right]`，不能写成另一种分区法的边界。

## 最小可运行示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

void quick_sort(std::vector<int>& a, int left, int right) {
    if (left >= right) return;

    int i = left - 1;
    int j = right + 1;
    int pivot = a[left + (right - left) / 2];

    while (i < j) {
        do { ++i; } while (a[i] < pivot);
        do { --j; } while (a[j] > pivot);
        if (i < j) std::swap(a[i], a[j]);
    }

    quick_sort(a, left, j);
    quick_sort(a, j + 1, right);
}

int main() {
    std::vector<int> a = {7, 2, 1, 6, 8, 5, 3, 4};
    quick_sort(a, 0, static_cast<int>(a.size()) - 1);
    for (int x : a) std::cout << x << ' ';
}
```

预期输出：

```text
1 2 3 4 5 6 7 8
```

## 如何验证

分别测试 `{1}`、`{2, 1}`、`{3, 3, 3}` 和已排序数组。空数组不应调用该函数，因为 `right` 会变为 `-1`；调用点应先判断 `a.empty()`。若把第二次递归错写为 `quick_sort(a, j, right)`，某些输入会反复递归同一区间。

## 复杂度与边界

- 平均 `O(n log n)`，分区反复极不平衡时最坏 `O(n^2)`。
- 额外空间主要是递归栈，平均 `O(log n)`，最坏 `O(n)`。
- 通常不稳定；相等元素可能因交换改变相对顺序。
- 基准选择会影响性能。面对攻击性输入或必须控制最坏情况时，不要直接依赖这段教学实现。
