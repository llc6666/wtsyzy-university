# 冒泡排序

反复比较相邻元素，若顺序错误就交换。每轮通常把一个最大元素推到未排序区间末端。

```cpp
void bubble_sort(int a[], int n) {
    for (int end = n - 1; end > 0; --end) {
        bool changed = false;

        for (int i = 0; i < end; ++i) {
            if (a[i] > a[i + 1]) {
                std::swap(a[i], a[i + 1]);
                changed = true;
            }
        }

        if (!changed) {
            break; // 已经有序
        }
    }
}
```

优点是原地、稳定，且可以通过 `changed` 识别已经有序的输入。缺点是平均和最坏情况都是 `O(n^2)`，只适合教学或数据很小的场景。
