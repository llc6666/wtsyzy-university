# 题面：二分查找

> 来源：exercism/c 仓库 `exercises/practice/binary-search`（MIT 许可）。中文译写，英文原件未保留。

任务：实现二分查找算法。

二分查找的做法是**反复把列表一分为二**，只保留可能包含目标值的那一半，不断缩小范围，直到找到目标，或者所有可能的位置都被排除。

**注意：二分查找只适用于已排序的列表。**

算法步骤：

- 在**已排序**的列表中取中间元素，与目标值比较
- 如果中间元素正好是目标，结束
- 如果中间元素**大于**目标，可以排除它以及它**后面**的所有元素
- 如果中间元素**小于**目标，可以排除它以及它**前面**的所有元素
- 如果所有元素都被排除了，说明目标不在列表中
- 否则，对剩下的那部分重复这个过程

示例：在 `[4, 8, 12, 16, 23, 28, 32]` 中找 23

- 先和中间元素 16 比较
- 23 大于 16，排除左半部分，剩下 `[23, 28, 32]`
- 再和新的中间元素 28 比较
- 23 小于 28，排除右半部分，剩下 `[23]`
- 找到了

## 官方签名（来自参考解）

```c
const int *binary_search(int value, const int *arr, size_t length);
```

找不到时返回 `NULL`；参考解还处理了 `length == 0` 与 `arr == NULL` 两种边界。

## 这一题的考点

- 区间怎么定（前闭后开还是两端都闭），中途不能变
- 中点计算写成 `low + (high - low) / 2`，避免 `low + high` 溢出
- 二分查找的前提是**有序**，无序数组要先排序
