# 大学 PPT 生产规范

## 1. 先判断课件类型

| 类型 | 核心问题 | 推荐结构 |
| --- | --- | --- |
| 课程汇报 | 你是否讲清一个知识问题 | 问题、结论、证据、解释、限制、参考文献 |
| 课题答辩 | 方案是否值得相信 | 问题、方法、数据、结果、贡献、风险、下一步 |
| 竞赛路演 | 为什么值得投入资源 | 痛点、用户、方案、验证、模型、需求 |
| 社团活动 | 听众下一步做什么 | 主题、价值、时间地点、流程、行动入口 |
| 求职展示 | 你做成过什么 | 背景、职责、行动、结果、反思 |

一页只回答一个问题。标题写结论，不写“研究背景”“案例分析”这类目录词。例如写“样本的增长主要来自二线城市”，正文才放数据和证据。

## 2. 版式与文字

- 16:9 优先。页面四周至少保留 0.5 英寸安全区。
- 投影场景下，标题 32 至 44 pt，正文 18 至 24 pt，图注不小于 14 pt。远程共享可略小，答辩教室不应降低。
- 同一页最多两层文字层级。段落超过三行，优先改成图、表、流程或拆页。
- 一套课件只确定一组主色、辅助色、强调色。强调色只用于需要被看见的数字、动作或判断。
- 图标保持同一套风格：线性图标不要和实心图标混用；同页图标线宽和视觉尺寸一致。

## 3. 数据、图片与引用

- 数据图必须包含：指标定义、单位、时间范围、数据来源。坐标轴截断时必须明确标记。
- 论文、报告、老师课件和网络截图不能只写“来源：网络”。写到可定位的作者、标题、机构、年份和链接或 DOI。
- 把作者、URL、许可证、下载日期放进项目的 `素材使用记录.csv`。最终页可用简化参考文献，原始记录保留在项目文件夹。
- 校徽、学校 Logo、企业 Logo 和人物肖像需要额外判断识别性和使用场景；素材库许可不替代商标权、肖像权或数据使用许可。

## 4. 制作与交付

1. 用一句话写出最终结论，列出支撑它的 3 到 5 个证据。
2. 先画低保真结构，确认叙事顺序，再做视觉设计。
3. 每完成 3 页，放到 100% 显示比例检查阅读顺序和对齐。
4. 导出 PDF，模拟投影或全屏查看。检查最小字号、图片清晰度、动画依赖和超链接。
5. 交付源文件、PDF、素材使用记录和演讲备注。需要在他人电脑展示时，提前进行字体替换测试。

## 5. 交付验收清单

- [ ] 每页标题都能独立表达结论或问题。
- [ ] 没有投影环境下难以读清的小字、浅灰字或过密段落。
- [ ] 图、表、图标、图片与正文之间至少有一个清晰的视觉层级。
- [ ] 数字、单位、年份、数据口径与原始来源一致。
- [ ] 每一个外来素材都能在项目使用记录中定位。
- [ ] 导出 PDF 后分页、字体、图片和动画降级效果符合预期。
- [ ] 最终文件名包含课程或项目、主题、版本、日期，例如 `2026秋-组织行为学-激励机制-v03-20260904.pptx`。
