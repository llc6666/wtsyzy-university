# 函数返回值：return 交回什么

## 一句话结论

函数的返回类型决定它交回什么：`void` 什么都不交，`int` 等类型交回一个对应类型的值。`return 表达式;` 是交回动作，函数执行到 return 立即结束并带回这个值。

## 它解决什么问题

函数算完结果后，要把结果交给调用方。没有返回值机制，函数只能靠输出或全局变量传递结果，无法作为"值"参与赋值、输出、运算。返回值让函数调用本身成为一个可用的值。

## 工作机制

```cpp
int add(int a, int b) {
    return a + b;    // 计算 a+b，把结果交回，函数结束
}

int main() {
    int x = add(3, 5);   // add(3,5) 整体 = 8，x 变成 8
    cout << add(3, 5);   // 直接输出 8
}
```

三个要点：

1. **返回类型**写在函数名前面，决定交回值的类型。`void` 表示"不交东西"。
2. **`return 表达式;`**：先计算表达式，把结果交回，然后函数立即结束，后面的代码不再执行。
3. **调用处**：`函数名(参数)` 这个整体就是那个值，可以赋值、输出、参与运算。

`void` 函数没有 return，或写 `return;`（只有分号，表示提前结束，不交值）：

```cpp
void print() {
    cout << "hi";
    return;          // 提前结束，不交东西
}
```

## 最小示例

```cpp
int size() {
    int cnt = 0;
    // 遍历计数...
    return cnt;      // 把计数器的值交回去
}

int main() {
    cout << l.size();   // 输出 return 交回来的那个数
}
```

## 常见错误与边界

1. **int 函数忘写 return**：函数体里没有 return，函数返回一个不确定的垃圾值，行为未定义。
2. **多分支忘 return**：一个分支 return 了，另一个分支忘了，编译器可能不报错但运行结果是垃圾值。
3. **return 的类型和返回类型不匹配**：例如 int 函数里 `return 3.14;`，小数部分被截断，只交回 3。
4. **void 函数里 return 值**：`void f() { return 5; }` 编译错误，void 函数不允许交回值。
5. **return 后还有代码**：`return` 之后的语句永远不会执行，是无用代码。

## 使用规则

- 先想清楚"这个函数要交回什么"，再定返回类型。
- 所有能走到函数结尾的路径都必须有 return。
- `return` 表达式的类型要和返回类型一致或能安全转换。
- 调用处把函数调用当值用，不要再写多余的临时变量（除非需要多次使用）。
