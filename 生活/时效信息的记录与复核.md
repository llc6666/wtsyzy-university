# 时效信息的记录与复核

## 结论

本地服务、办事流程、价格、路线、课程安排和活动规则都应当作带时间戳的信息使用。记录可以降低搜索成本，行动前复核才能降低错误成本。

## 最小记录字段

| 字段 | 说明 |
| --- | --- |
| 信息项 | 具体要解决什么问题 |
| 来源 | 官方页面、现场确认或个人体验 |
| 获取日期 | 何时得到的信息 |
| 适用范围 | 面向谁、在哪个地点或版本下有效 |
| 复查方式 | 使用前去哪里确认 |
| 状态 | 有效、待复核或已失效 |

## 做法

1. 按用途分类记录，而非按信息来源堆放。
2. 区分正式、相对稳定的信息与短期变化的信息。
3. 对高影响或高变化事项设定复查日期。
4. 行动前重新确认状态、时间、范围和成本。
5. 发现失效信息时标注失效或删除，避免它继续误导后续决策。

## 边界

个人体验只能说明特定时间和地点的情况。过期清单不应被包装为推荐。涉及安全、健康、法律、财务和学校制度的事项，需要以当下官方来源为准。
