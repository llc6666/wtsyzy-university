# C 语言与 STM32 编程练习库

这里收录一套面向“练习写代码、读代码”的公开材料：12 个 C 语言知识主题、6 个 STM32/嵌入式专题，以及对应的可编译小程序。

每个主题按同一结构组织：

- `README.md`：知识点、边界和关联关系
- `读-示例分析.md`：对代码结构与错误的分析；外来代码片段已省略
- `写-练习记录.md`：练习任务、验收条件和复盘入口
- `嵌入式实例.md`：把 C 知识映射到单片机场景
- `.c/.h`：本库自写的最小可运行示例

## 验证口径

PC 示例按 C17、`-Wall -Wextra -Wpedantic -Werror` 编译；可执行程序运行退出码为 0，汇编探针只检查生成的汇编。PC 验证只覆盖逻辑、边界和数据结构，不替代芯片手册、原理图、示波器波形或真实开发板验证。

## 公开边界

本目录默认只发布本人整理的说明、练习设计和自写示例。本批次按[公开特批说明](公开特批说明.md)增加了处理后的题面、参考解和参考素材副本；下载压缩包、原始解压目录和完整工程仍留在本地参考资料层。
