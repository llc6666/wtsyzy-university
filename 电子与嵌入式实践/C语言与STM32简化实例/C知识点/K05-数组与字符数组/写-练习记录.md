## reverse-string

- 签名：`char *reverse(const char *value)`
- 题面要点：`"stressed"` → `"desserts"`；回文反转后不变
- 所有权：函数 `malloc`，调用方 `free`

### 验收标准（用例表 + 五类边界）

| 输入 | 期望 |
| --- | --- |
| `"stressed"` | `"desserts"` |
| `"strops"` | `"sports"` |
| `"racecar"` | `"racecar"` |
| `"a"` | `"a"` |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `""` | `""`（分配 1 字节只放 `\0`，不能返回 NULL 导致调用方崩溃） |
| 最小 | `"a"` | `"a"` |
| 最大 | 很长的字符串 | 分配尺寸正确，不越界写 |
| 相等 | 回文 `"racecar"` | 与原串相同 |
| 非法 | 传入 NULL | 不得解引用；返回 NULL 或空串需明确约定 |

- 不变量：返回的内存由调用方释放；结果必须以 `\0` 结尾；`strlen(结果) == strlen(输入)`

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**：原地反转（不分配）也可行，但会修改输入；这一题的契约是返回新串，要分清两种做法
3. **哪里最容易错**：`malloc(len)` 忘了 `+1`；原地反转版本不能用字符串字面量做参数（写在只读区会崩）

## acronym

- 题面要点：连字符是分隔符，其他标点忽略；结果转成大写
- 接口以头文件为准；参考解用 `isalpha` + 「前一个字符是空格/连字符/下划线」判断单词开头

### 验收标准（用例表 + 五类边界）

| 输入 | 期望 |
| --- | --- |
| `As Soon As Possible` | `ASAP` |
| `Liquid-crystal display` | `LCD` |
| `Thank George It's Friday!` | `TGIF` |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `""` | `""`，不崩溃 |
| 最小 | 单个单词 `"Portable"` | `P` |
| 最大 | 很长的短语 | 结果缓冲区够用，不越界 |
| 相等 | 连续两个分隔符 `"a  b"`（两个空格） | 只算一个单词开头 |
| 非法 | 全标点输入 `"!!!"` | 空串 |

- 不变量：结果全大写；以 `\0` 结尾；原输入不被修改

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**
3. **哪里最容易错**：`isalpha` 传了可能为负的 `char`；把撇号当成单词开头（`It's` 的 s 不算新单词）
