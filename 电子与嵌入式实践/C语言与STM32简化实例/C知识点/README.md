# C 语言知识点练习

这 12 个主题按“先能编译运行，再读边界，再映射到嵌入式”的顺序排列。每个目录都保留自己的说明、读码分析、练习记录和小程序。

| --- | --- | --- |
| K01 | [编译与最小 C 程序](K01-编译与最小C程序/README.md) | 声明、定义、编译与链接 |
| K02 | [类型与固定宽度整数](K02-类型与固定宽度整数/README.md) | 位宽、溢出、格式化输出 |

## 练习顺序

先完成 K01–K06，再完成 K07–K09，随后做 K10–K12。每个主题至少完成一次“改一个边界条件、重新编译、解释输出”的循环。

第三方题面和参考解没有复制到公开库；需要查原题时回到本地参考资料层的来源登记。
