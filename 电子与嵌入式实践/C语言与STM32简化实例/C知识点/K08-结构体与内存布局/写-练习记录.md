## complex-numbers

- 接口以头文件为准；参考解用 `complex_t { double real; double imag; }`
- 题面要点：禁止使用内置复数支持，自己实现七种运算
- 关键公式（题面给了，见素材里的题面）：乘法 `(a*c - b*d) + (b*c + a*d)i`；除法分母 `c² + d²`；模 `sqrt(a² + b²)`

### 验收标准（用例表 + 五类边界）

| 运算 | 输入 | 期望 |
| --- | --- | --- |
| 加 | `(1,2) + (3,4)` | `(4,6)` |
| 减 | `(1,2) - (3,4)` | `(-2,-2)` |
| 乘 | `(1,2) * (3,4)` | `(1*3-2*4, 2*3+1*4) = (-5,10)` |
| 共轭 | `(1,2)` | `(1,-2)` |
| 模 | `(3,4)` | `5` |
| 除 | `(1,2) / (3,4)` | `(0.44, 0.08)`（分母 25） |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | 零复数 `(0,0)` | 模为 0；共轭仍是 `(0,0)` |
| 最小 | 极小值 | 不出现除零 |
| 最大 | 很大的实部虚部 | `a² + b²` 不溢出（`double` 范围内） |
| 相等 | `z + 0` 与 `z` | 相等 |
| 非法 | 除以零复数 | 需明确约定（返回什么、是否报错） |

- 不变量：运算不修改输入；`|z|² == z * conj(z)`；`z / z == (1,0)`

### 复盘三问

1. **为什么对**
2. **暴力做法为什么不行**：这一题就是按公式实现，没有算法优劣；「暴力」的差别在于是否把公共式子（如 `a²+b²`）抽成函数
3. **哪里最容易错**：除法忘了除以 `c²+d²`；指数运算的欧拉公式符号

## clock

- 题面要点：只管时间不管日期；能加减分钟；表示同一时刻的两个时钟相等
- 关键：加减后要归一化到 0–23 时、0–59 分，负数分钟要处理

### 验收标准（用例表 + 五类边界）

| 操作 | 期望 |
| --- | --- |
| 创建 `10:00`，加 30 分钟 | `10:30` |
| 创建 `23:59`，加 1 分钟 | `00:00` |
| 创建 `00:30`，减 60 分钟 | `23:30` |
| `09:00` 与 `33:00`（加一天） | 相等 |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | 创建 `00:00` | `00:00` |
| 最小 | 加 0 分钟 | 不变 |
| 最大 | 加 10000 分钟 | 正确绕回（不是溢出） |
| 相等 | 两个不同表示但同一时刻 | 相等（比较归一化结果，不是比较字段） |
| 非法 | 减很多分钟（跨多天） | 正确绕回；负数取模不要依赖实现定义的行为 |

- 不变量：显示格式固定两位（`%02d:%02d`）；任何操作后时 ∈ [0,23]、分 ∈ [0,59]

### 复盘三问

1. **为什么对**
2. **暴力做法为什么不行**：用 `while` 循环加减也能做，但加 10000 分钟会跑一万次；用取模更好，但要处理负数
3. **哪里最容易错**：负数分钟用 `%` 取模（C 里结果符号依实现而定）；只比较结构体字段导致两个相同时刻不相等
