# 低成本验证机会选择

## 结论

面对一项机会，先用小规模、可退出的任务验证它是否匹配目标、能力和资源，再决定是否长期投入。

## 四个判断变量

| 变量 | 要问的问题 |
| --- | --- |
| 目标关联 | 它服务于当前哪个目标？ |
| 真实任务 | 实际需要承担什么责任？ |
| 投入成本 | 时间、精力、机会成本和退出成本是多少？ |
| 反馈质量 | 多久能获得谁提供的真实反馈？ |

宣传、名气、头衔和他人评价只能帮助发现候选项，不能直接证明一项机会值得投入。

## 验证流程

1. 建立候选表，记录目标、任务、周期、门槛和退出条件。
2. 优先选择周期短、反馈快、产出清晰的试做任务。
3. 进入前确认自己的具体责任，而不是只确认职位名称。
4. 设置一个明确验证窗口，到期检查是否产生真实任务和反馈。
5. 证据充分后再加大投入；没有价值证据时及时退出。
6. 保留成果、反馈和复盘，不把报名记录当成成果。

## 边界

有些能力需要长期积累，短期没有明显产出不代表机会无价值。低成本试错也不能无限并行，团队质量、导师投入和个人承担程度仍会改变结果。

## 自检

- 我实际承担什么任务？
- 最坏情况下的时间损失是多少？
- 何时能获得可验证的反馈？
- 最后能留下什么可复查成果？
