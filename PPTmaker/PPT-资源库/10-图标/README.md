# 图标库使用说明

公开版只保留选型、来源和使用规则，不镜像第三方图标包。需要本地 SVG 时，从下列官方项目获取，并将实际版本、许可证和下载日期写入项目记录。

| 图标库 | 本地路径 | 视觉特征 | 适合的页面 |
| --- | --- | --- | --- |
| [Lucide](https://github.com/lucide-icons/lucide) | 按官方版本获取 | 细线、留白多、语义覆盖广 | 研究流程、方法、时间线、工具类内容 |
| [Bootstrap Icons](https://github.com/twbs/icons) | 按官方版本获取 | 实心、识别强、信息密度高 | 数据卡片、状态、目录、操作提示 |
| [Heroicons](https://github.com/tailwindlabs/heroicons) | 按官方版本获取 | 线性与实心成对 | 极简展示、产品或项目方案 |

PowerPoint 中可通过“插入 → 图片 → 此设备”放入 SVG。改变颜色前先复制一份，避免覆盖来源文件。

同一页只选一种体系。需要强调时用同一图标的实心版本，不能改用另一套图标风格。
