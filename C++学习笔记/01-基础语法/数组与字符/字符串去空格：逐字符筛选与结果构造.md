# 字符串去空格：逐字符筛选与结果构造

## 一句话结论

去除字符串中的空格，先用 `getline` 读入整行，再逐个检查字符，只输出或保存不需要删除的字符。

## 头文件

```cpp
#include <iostream>  // 提供 std::cin 和 std::cout
#include <string>    // 提供 std::string
```

## 直接输出筛选结果

```cpp
#include <iostream>               // 提供标准输入输出
#include <string>                 // 提供字符串类型

int main() {
    std::string s;                // 保存输入的一整行
    std::getline(std::cin, s);    // 读取整行，保留其中的空格

    for (char ch : s) {           // 依次取出字符串中的每个字符
        if (ch != ' ') {          // 只保留不是普通空格的字符
            std::cout << ch;      // 立即输出保留下来的字符
        }
    }

    std::cout << '\n';            // 输出换行
    return 0;                     // 程序正常结束
}
```

输入：

```text
#Poltu is new here
```

输出：

```text
#Poltuisnewhere
```

## 保存为新字符串

如果后面还要继续处理结果，应该创建一个新字符串：

```cpp
#include <iostream>               // 提供标准输入输出
#include <string>                 // 提供 string 类型

int main() {
    std::string s;                // 保存原始输入
    std::string result;           // 保存去除空格后的结果
    std::getline(std::cin, s);    // 读取整行字符串

    for (char ch : s) {           // 遍历原字符串的每个字符
        if (ch != ' ') {          // 判断当前字符是否为普通空格
            result += ch;         // 将保留字符追加到结果末尾
        }
    }

    std::cout << result << '\n';  // 输出处理后的字符串
    return 0;                     // 程序正常结束
}
```

## C++98 写法

范围 `for` 是 C++11 语法。旧版编译器可以使用字符数组和普通下标循环：

```cpp
#include <iostream>               // 提供标准输入输出

int main() {
    char s[101];                  // 最多保存 100 个输入字符和结尾的 '\0'
    std::cin.getline(s, 101);     // 读取一整行，最多读取 100 个字符

    for (int i = 0; s[i] != '\0'; ++i) { // 遍历到字符串结束标记
        if (s[i] != ' ') {        // 过滤普通空格
            std::cout << s[i];    // 输出当前保留字符
        }
    }

    std::cout << '\n';            // 输出换行
    return 0;                     // 程序正常结束
}
```

## 只删除普通空格，还是删除所有空白

```cpp
if (ch != ' ') {                  // 只删除普通空格
    std::cout << ch;               // 制表符等其他字符仍会保留
}
```

如果题目要求删除空格、制表符、换行等空白字符，可以使用 `<cctype>` 的 `std::isspace`：

```cpp
#include <cctype>                 // 提供 std::isspace

if (!std::isspace(                 // 判断当前字符是否不是空白字符
        static_cast<unsigned char>(ch))) {
    result += ch;                 // 保存非空白字符
}
```

`std::isspace` 的参数应转换为 `unsigned char`，或传入 `EOF`；直接把可能为负值的 `char` 传入，可能产生未定义行为。

## 常见误区

1. 把字符和字符串比较：`ch != " "` 错误，单个字符应使用 `' '`。
2. 使用 `cin >> s` 读取含空格的整行，后续内容会丢失。
3. 题目只要求删除普通空格，却误用 `isspace`，导致制表符等字符也被删除。
4. 在遍历字符串时修改下标或长度，容易漏读字符；筛选任务优先使用结果字符串。
