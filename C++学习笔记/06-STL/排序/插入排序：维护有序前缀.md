# 插入排序：维护有序前缀

## 什么时候用

数组很小，或数据大部分已经有序时。竞赛和工程代码里的通用选择通常仍是 `std::sort`；这里的目标是理解“移动元素后再放回空位”的过程。

## 机制

把下标 `0..i-1` 看作有序前缀。取出 `a[i]` 到变量 `value`，从右向左把所有大于 `value` 的元素右移一格，最后把 `value` 写入腾出的 `j+1`。这里移动的是元素，不是交换相邻元素。

当比较条件是 `a[j] > value` 时，值相等的元素不会跨过彼此，所以它稳定。

## 最小可运行示例

```cpp
#include <iostream>
#include <vector>

void insertion_sort(std::vector<int>& a) {
    for (int i = 1; i < static_cast<int>(a.size()); ++i) {
        int value = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > value) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = value;
    }
}

int main() {
    std::vector<int> a = {5, 2, 4, 2, 1};
    insertion_sort(a);
    for (int x : a) std::cout << x << ' ';
}
```

预期输出：

```text
1 2 2 4 5
```

## 如何验证

把输入改成 `{1, 2, 3, 4}`。循环仍会执行，但内层 `while` 从不搬动元素，比较次数约为 `n-1`，这就是接近有序时它快的原因。

## 复杂度与边界

- 最好：已排序时 `O(n)`。
- 平均和最坏：`O(n^2)`。
- 额外空间：`O(1)`，原地排序，稳定。
- 不适合百万级随机数据；此时优先 `std::sort`。
- `j` 必须用有符号整数。若写成无符号 `size_t`，`--j` 到零后会回绕，`j >= 0` 永远为真。
