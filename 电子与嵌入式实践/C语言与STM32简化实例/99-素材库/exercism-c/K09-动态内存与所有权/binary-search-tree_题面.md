# 题面：二叉搜索树

> 来源：exercism/c 仓库 `exercises/practice/binary-search-tree`（MIT 许可）。中文译写，英文原件未保留。

在一棵二叉树里插入数字、查找数字。

当需要表示**有序**数据时，数组不是个好结构。比如数组 `[1, 3, 4, 5]`，加入 2 变成 `[1, 3, 4, 5, 2]`，就得重新排序一遍。就算只在中间腾个位置 `[1, nil, 3, 4, 5]`，也要把后面许多元素整体后移。

二叉搜索树（BST）处理有序数据要高效得多。

BST 由一串相互连接的节点组成。每个节点包含：一个数据（比如数字 3）、一个 `left`、一个 `right`。`left` 和 `right` 要么指向空，要么指向别的节点；那些节点下面又有节点，所以称它们为子树。

规则：**左子树里的所有数据 ≤ 当前节点的数据，右子树里的所有数据 > 当前节点的数据。**

举例（原题用 SVG 示意图，这里用字符图还原）：

先有一个节点 4，加入 2：

```text
      4
     /
    2
```

再加入 6：

```text
      4
     / \
    2   6
```

再加入 3：

```text
       4
     /   \
    2     6
     \
      3
```

再依次加入 1、5、7：

```text
          4
        /   \
       /     \
      2       6
     / \     / \
    1   3   5   7
```

## 这一题的考点

- 每个节点用 `malloc` 创建，用完了要 `free`——**所有权**是这一题真正的难点
- 插入时用「小于等于走左边、大于走右边」的规则递归或迭代
- 递归实现要处理空树（根节点为 NULL）的情况
- 参考解里有 `free_tree()`：销毁整棵树时要递归释放每一个节点，只释放根节点会造成内存泄漏
