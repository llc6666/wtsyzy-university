## 复现命令

单文件示例可在对应目录执行：

```text
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror 文件.c -o 文件.exe
文件.exe
```

K10 汇编探针：

```text
gcc -std=c17 -O2 -Wall -Wextra -Wpedantic -S volatile-asm-probe.c -o volatile-asm-probe.s
```

K11 多文件示例：

```text
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror multifile-demo/main.c multifile-demo/sensor.c -o multifile-demo.exe
multifile-demo.exe
```

## 复核重点

1. C 主题：类型边界、位移位宽、字符串结尾、数组长度、指针步长、结构体偏移、内存所有权和链接属性。
2. 并发边界：`volatile` 只解决编译器访问可见性；PC 线程示例使用原子变量，不能把 `volatile` 当线程同步原语。
3. 嵌入式边界：GPIO、UART、OLED、时基和传感器程序均为逻辑模拟；引脚、时钟、寄存器、供电和电平必须另按芯片与板卡资料验证。
