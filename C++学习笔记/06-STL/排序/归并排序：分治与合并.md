# 归并排序：分治与合并

## 什么时候用

需要稳定排序，或想理解“先分别解决，再合并结果”的分治结构时。日常排序先用 `std::sort`；需要稳定性时优先考虑 `std::stable_sort`。

## 机制

把区间分成左右两半，直到每段只剩一个元素。两个单元素段天然有序，再用两个指针比较两段当前最小元素，依次写入临时数组。合并后把临时数组写回原区间。

比较时使用 `<=`，相等值优先取左段元素，因此左段相等元素不会被右段元素越过，排序稳定。

## 最小可运行示例

```cpp
#include <iostream>
#include <vector>

void merge_sort(std::vector<int>& a, std::vector<int>& temp, int left, int right) {
    if (left >= right) return;

    int mid = left + (right - left) / 2;
    merge_sort(a, temp, left, mid);
    merge_sort(a, temp, mid + 1, right);

    int i = left, j = mid + 1, k = left;
    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) temp[k++] = a[i++];
        else temp[k++] = a[j++];
    }
    while (i <= mid) temp[k++] = a[i++];
    while (j <= right) temp[k++] = a[j++];
    for (int p = left; p <= right; ++p) a[p] = temp[p];
}

int main() {
    std::vector<int> a = {38, 27, 43, 3, 9, 82, 10};
    std::vector<int> temp(a.size());
    merge_sort(a, temp, 0, static_cast<int>(a.size()) - 1);
    for (int x : a) std::cout << x << ' ';
}
```

预期输出：

```text
3 9 10 27 38 43 82
```

## 如何验证

在处理 `{2, 1, 2}` 时，最后应输出 `1 2 2`。若排序的是含“值、原始编号”的结构体，保持比较相等时先取左段，就能验证相等值的编号没有颠倒。把 `temp` 错开为只在每次递归新建，会增加不必要的分配；上例只创建一次并复用。

## 复杂度与边界

- 任意输入的时间复杂度均为 `O(n log n)`。
- 需要 `O(n)` 临时数组，不是原地排序。
- 空数组应在调用前跳过，否则 `size() - 1` 的无符号运算可能出错；上例针对非空数组。
- 必须在两个子区间已各自有序后才合并，不能跳过递归直接合并原始区间。
