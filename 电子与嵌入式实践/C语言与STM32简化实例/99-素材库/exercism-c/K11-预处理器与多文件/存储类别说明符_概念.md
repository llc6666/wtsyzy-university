# 概念：存储类别说明符

> 来源：exercism/c 仓库 `concepts/storage-class-specifiers/about.md`（MIT 许可）。本文为中文要点译写，英文原件未保留。

存储类别说明符决定变量**存在哪里、活多久**。

## auto：函数或块作用域变量的默认类别

- 块/函数里定义的变量默认就是 `auto`，所以几乎没人显式写它
- 另一个不写的原因是：`auto` 在 C++ 里是完全不同的含义，混编工程里容易混淆
- `auto` 变量的生命期：进入块时开始，离开块时结束
- **分配了内存，但没有默认值**（未初始化的局部变量内容是垃圾值）
- 变长数组（VLA）是例外：分配发生在声明处

## static：两种含义，别混

| 场景 | 含义 |
| --- | --- |
| 文件作用域的变量 | 表示**内部链接**（见《链接属性与 static》） |
| 函数或块内的变量 | 表示**静态存储期**：程序开始就存在，值在多次调用之间保留 |

函数内的 `static` 变量如果没显式初始化，**会被初始化为零**（这一点和 `auto` 不同）。

```c
#include <stdio.h>

void print_stuff(void) {
    static int count;          /* 静态存储期，初始为 0 */
    count++;
    printf("函数里的 count 是 %d\n", count);
    {
        static int count;      /* 块里的另一个 count，遮蔽外层的 */
        count++;
        printf("块里的 count 是 %d\n", count);
    }
}

int main(void) {
    print_stuff();   /* 函数里的 count 是 1 / 块里的 count 是 1 */
    print_stuff();   /* 函数里的 count 是 2 / 块里的 count 是 2 */
}
```

`static` 变量如果显式初始化，**必须用常量表达式**（编译期就能算出来的值）。

## extern：访问另一个翻译单元里的变量

**翻译单元** = 一个源文件 + 它 `#include` 进来的所有文件。

- `extern` 通常用来**引用**一个已经存在的变量，而不是定义新变量
- 被引用的变量必须具有文件作用域
- 被包含文件里的变量要具有外部链接，包含它的文件才能访问

## 与嵌入式的关系

- 函数里的 `static` 变量会占用 RAM 的静态区，而不是栈——在栈很小的 MCU 上，这是把大数组挪出栈的常用手段
- 文件作用域的 `static` 用来隐藏模块内部实现，避免不同 `.c` 文件里的同名符号打架
- 未初始化的局部变量是垃圾值，这一点在嵌入式上表现为「上电后行为随机」，很难查
