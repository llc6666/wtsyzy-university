# 插画与表情使用说明

公开版不镜像 OpenMoji 或其他第三方插画包，只保留来源、许可和实际使用规则。需要素材时，从 [OpenMoji 官方仓库](https://github.com/hfg-gmuend/openmoji) 获取具体版本，并在项目记录中保存 URL、下载日期和署名文案。

它适合低风险提示、过程状态、轻量课堂互动和目录标识，不适合替代正式数据图或论文配图。

许可证为 CC BY-SA 4.0。使用时在最终页、备注页或项目素材记录中至少保留：

`Emoji designed by OpenMoji — CC BY-SA 4.0；已修改颜色/大小。`

公开传播包含改编表情的文件前，再核对 CC BY-SA 的署名与相同方式共享要求。
