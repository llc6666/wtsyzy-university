# 概念：链接属性与 static

> 来源：exercism/c 仓库 `concepts/linkage/about.md` 与 `concepts/static-functions/about.md`（MIT 许可）。本文为中文译写，英文原件未保留。

**链接属性**描述一个标识符能被程序的哪些部分访问。

- 块作用域、函数作用域、函数原型作用域里的标识符**没有链接属性**，只能在自己的作用域内访问
- 文件作用域的标识符**默认是外部链接**（external linkage），程序里任何文件都能用
- 文件作用域的标识符加上 `static` 就变成**内部链接**（internal linkage），只能在自己的文件里用

```c
int public_count = 0;         /* 文件作用域，默认外部链接 */
static int private_count = 0; /* 文件作用域，内部链接 */

static void some_function(void)   /* 内部链接：只在本文件可见 */
{
    /* … */
}

int main(void)                    /* 外部链接（main 特殊） */
{
    /* … */
}
```

## 一个必须记住的陷阱

如果一个变量在**头文件里声明**，却在源文件里被定义成 `static`（内部链接）并给了初值，那么：

- 它能编译、能链接、能运行，**不报错**
- 但从别的文件访问这个变量时，读到的值是**零值**，即使你用了 `extern`

原因：`static` 让它只在自己的文件里可见，别的文件 `extern` 到的其实是另一个未初始化的同名变量。

规则：**在源文件里标了 `static` 的变量，就不要在头文件里声明它。**

## `static` 的两个含义（不要混淆）

| 用在哪里 | 含义 |
| --- | --- |
| 文件作用域的变量或函数前 | 改变**链接属性**：只在本文件可见 |
| 函数内部的变量前 | 改变**存储期**：值在多次调用之间保留 |

同一个关键字，两种完全不同的作用，这是 C 里最容易混淆的地方之一。
