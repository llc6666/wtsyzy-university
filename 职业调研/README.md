# 职业调研

这里保存带日期的公开岗位快照和由样本提炼出的能力路线。岗位状态、薪资、城市和学历要求都可能变化，阅读后准备投递时必须重新打开原始页面。

- [电子信息与 AI 交叉能力地图](电子信息与AI交叉能力地图.md)：从岗位动词提取输入、工具、产物和指标的方法。

## 使用边界

- 公开快照是采集日证据，不是当前招聘列表，也不是行业总体统计。
- 薪资按来源口径原样保留；“未披露”不等于零，也不能据此计算平均值。
- 高校就业网、聚合站和搜索摘要只支持页面明确写出的信息；投递前优先回到企业官方招聘系统。
- 未公开原始来源记录、学校培养方案、社团名单、个人规划、聊天记录和第三方长篇材料。

## 推荐流程

1. 先按对象域筛选岗位，不按公司名或薪资排序。
2. 打开原始页面，记录发布日期、岗位状态、学历、城市、薪资口径和投递渠道。
3. 把重复出现的任务动词整理成能力缺口。
4. 用一个两到八周的可复现项目验证最大缺口，再更新方向判断。

配套方法见 [岗位样本与市场信息采集](../方法论/职业规划/岗位样本与市场信息采集.md) 和 [低成本职业验证项目](../方法论/职业规划/低成本职业验证项目.md)。
