# C 与嵌入式编程练习库

这是一个**练习型**小知识库：外来开源资料是原材料，本库记录的是「读什么、写什么、拿它练什么」，以及把通用 C 映射到 STM32 SPL 的简化实例。

原始 ZIP 与解压目录**一律不动**，它们只是被引用的原材料；本目录下新建的 `00-索引与说明/`、`01-知识点/` 与 `99-素材库/` 才是加工产物。

**本库自包含**：整体搬走时**不需要**带走原始下载目录。做题要用的题面、参考解、接口头文件、教程章节，在 `99-素材库/` 里都有一份副本；知识点笔记只指这里，不指原始目录。

**测试文件不带**：exercism 的 `test_*.c` 与 unity 框架不入库（框架单份 241 KB、每题重复一份）。替代做法是每题写一份**验收标准**——函数签名、用例表、五类边界、不变量，凭它可以让任意 AI 或自己生成测试。想跑原版测试时才回原始目录 `make test`。

## 这套库怎么用

每个知识点目录里固定四件东西，按「读 → 写 → 落到嵌入式 → 记住坑」的顺序走：

| 文件 | 回答的问题 | 状态含义 |
| --- | --- | --- |
| `README.md` | 这个知识点一句话是什么、易错点有哪些 | 枢纽页，先读它 |
| `读-示例分析.md` | 原始资料里哪一份代码值得读、逐行在做什么 | 读代码线 |
| `写-练习记录.md` | 要写哪几题、做到哪一步、复盘结论 | 写代码线 |
| `嵌入式实例.md` | 这个知识点在 STM32 上长什么样，PC 上怎么先跑通 | PC 可编译 + SPL 对照 |

每个知识点还有一段可直接编译的 C 文件（就在该目录下），命令与实测输出都写在 `嵌入式实例.md` 里，不写没跑过的命令。

## 分层方式

采用「知识点 + 阶段」混合：知识点决定**目录**，阶段决定**顺序**。

- 目录按知识点切：一个知识点一个目录，目录内同时挂「读的示例」和「写的练习」，避免同一主题的内容分居两处。
- 顺序按阶段推进：`K01 → K12` 就是学习顺序，前面是后面的地基（指针在 K07，但 K03 的寄存器操作会提前用到地址概念，靠 K01 的编译模型打底）。
- 每个知识点都带一个**嵌入式简化实例**：同样的 C 语法，在 PC 上用普通变量模拟寄存器跑通，再对照真实 SPL 写法。这样在没有开发板时也能练。

## 与其他库的关系

- 本库：**练习场**。外来资料的分析、练习题的推进记录、PC 可编译的嵌入式实例。
- `codeing/编程/c`：正式 C 知识库。本库里经本人反复写对、能讲清原理的结论，才回填到那里。
- `嵌入式/02-STM32`：嵌入式知识库。本库的 SPL 对照片段属参考，正式笔记仍以那边为准。
- 公开库 `wtsyzy-university-md`：本批 `99-素材库` 按特批公开；其他外来资源仍按《资源来源登记》中的许可与边界处理。
