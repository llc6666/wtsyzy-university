# 字体使用说明

公开版只记录字体来源与使用边界，不携带字体二进制文件。课程汇报优先选择展示电脑已有、跨设备回退稳定的字体。

| 字体 | 用途 | 许可证 | 官方来源 |
| --- | --- | --- | --- |
| Noto Sans SC | 中文正文、标题、数字 | SIL Open Font License 1.1 | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc) |
| Source Han Sans | 需要多字重的中文正文 | SIL Open Font License 1.1 | [Adobe Fonts](https://github.com/adobe-fonts/source-han-sans) |
| Source Han Serif | 人文、文学类引文或封面 | SIL Open Font License 1.1 | [Adobe Fonts](https://github.com/adobe-fonts/source-han-serif) |

## 使用步骤

1. 从官方仓库获取具体版本，并确认许可证文件随版本保存。
2. 在目标电脑打开源文件，检查缺字、替换和行距变化。
3. 导出 PDF，再检查分页、字形和链接。
4. 在项目素材记录中写字体名称、版本、来源、许可证和复核日期。

字体许可不等于课件内容许可；论文配图、校徽、企业 Logo 和人物肖像仍需单独核验。
