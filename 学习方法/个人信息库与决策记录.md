# 个人信息库与决策记录

## 结论

信息库的核心价值不在收藏，而在于来源、时间和决策都能回溯。它把“我记得有人这么说过”变成“这条信息在什么条件下可用”。

## 三条可追溯性

- **来源可追溯**：区分官方文件、原始材料、个人经验和二手转述。
- **时间可追溯**：标记适用对象、版本和获取日期。
- **决策可追溯**：记录选项、约束、证据、暂定选择与复查条件。

## 最小决策记录

| 字段 | 内容 |
| --- | --- |
| 问题 | 要解决的具体选择 |
| 选项 | 可行方案，而非单一愿望 |
| 约束 | 时间、成本、能力与制度限制 |
| 证据 | 来源、日期与可信度 |
| 暂定选择 | 当前行动与理由 |
| 复查条件 | 何时、出现什么新证据后重审 |

## 做法

1. 新资料先保留最小元数据：来源、日期、主题、适用对象。
2. 把事实、自己的判断和待验证问题分开保存。
3. 只为高影响决策建立完整记录。
4. 对易变信息设置复查日期。
5. 用结果修正记录，让信息库成为反馈系统。

## 边界

记录不能代替行动。单一经验也不能自然升级为通用结论。信息维护成本高，应优先服务当前真正会影响选择的问题。
