# PPT 资源库

## 目标

把“临近汇报才找模板”的随机过程，变成可检索、可引用、可复用的制作系统。公开版重点保留规则、来源、许可证和检查动作；第三方大资源包按官方来源获取，不在此仓库镜像。

## 本次补充的三层能力

| 层 | 解决的问题 | 固化位置 |
| --- | --- | --- |
| 叙事与信息结构 | 一页只承载一个结论，整份课件形成证据链，而非把资料堆成页 | `30-制作规范/大学PPT生产规范.md` |
| 版权与素材治理 | 每个外来素材都有来源、许可证、署名义务和使用记录 | `00-治理/素材许可证总表.csv`、`00-治理/素材使用记录模板.csv` |
| 输出质检与复用 | 保证投影可读、引用可追溯、导出稳定，并将成熟内容升级成组件或模板 | `30-制作规范/大学PPT生产规范.md` |

## 使用顺序

1. 先写一句话结论和听众问题，再选版式。不能先选模板。
2. 在 `10-图标`、`20-插画与表情` 或 `40-在线来源` 确定来源。需要本地文件时，从官方项目按登记版本获取；优先 SVG，避免截图和带水印 PNG。
3. 每次拿外来图片、图表、学校标志或数据，向项目目录复制 `00-治理/素材使用记录模板.csv` 并补齐一行。
4. 如果已经按官方来源准备了本地资源包，执行 `工具/生成图标索引.ps1`、`工具/核验资源库.ps1`，并按生产规范做投影可读性检查。

## 不收集的内容

- 来路不明的商业模板、字体、论文配图、影视截图、品牌 Logo 合集。
- 从 Unsplash、Pexels、unDraw 等服务批量抓取的图片。它们适合按项目逐张取用，不允许被当成二次素材库再分发。
- 缺来源、缺许可证或只能用“网上找的”解释的文件。

## 更新原则

新增一项资源必须同时补三个字段：原始 URL、许可证、收集日期。可变版本的仓库和 npm 包还要记录版本号或提交哈希。只记录链接而不写使用边界，后续仍然会失控。公开提交前还要确认没有把本地项目课件或个人信息带入资源库。
