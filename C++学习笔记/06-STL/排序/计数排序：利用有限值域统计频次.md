# 计数排序

适合整数值域较小的情况：

```cpp
int a[] = {2, 1, 3, 2, 0};
int count[4] = {};

for (int x : a) {
    ++count[x];
}

for (int value = 0; value <= 3; ++value) {
    for (int k = 0; k < count[value]; ++k) {
        std::cout << value << ' ';
    }
}
```

如果最大值非常大而元素数量很小，计数数组会浪费空间。复杂度中的 `r` 指值域范围，不是元素数量本身。
