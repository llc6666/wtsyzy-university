# 第一册：进入终端，先确认当前环境

**目标：**填一张环境记录卡：当前主机角色、用户、目录、发行版、内核、要用的命令及其来源。准备本地 Linux、虚拟机或 WSL；如已有自己管理的 OpenWrt 设备，可选择授权 SSH 会话。以下观察不改设备配置。

## 1. 区分本地与远程

本地终端窗口里的命令起初由本地 Shell 处理，SSH 登录成功后则由远端的 Shell 处理。进入或退出远程会话后，可以用下面的只读观察确认环境：

```sh
id
pwd
uname -r
cat /etc/os-release
command -v sh
command -v grep
```

- `id` 查实际用户和组；提示符可自定义，不能只凭 `#` 或 `$` 判断权限。
- `pwd` 显示当前目录。若它是 `/etc`，相对路径 `config` 从 `/etc` 解释；`/etc/config` 从根目录解释。
- `uname -r` 查内核版本，`/etc/os-release` 查发行版（文件不存在时查该系统的版本说明）。两项回答的问题不同。
- `command -v` 查当前 Shell 识别到的命令；无结果时先查拼写、PATH，再查是否安装。普通外部命令、Shell 内建和别名可能有不同的帮助入口。

从自己的 SSH 客户端连接已获授权的设备时，按管理员分配的用户名、地址和端口填写。初次连接，先通过可信的本地控制台或资产交付记录核对主机密钥指纹，再确认。已经登记的密钥突然变化时，先查设备更换、重装或地址漂移；别先清掉旧记录，也别关闭主机密钥检查。退出时用 `exit`，再确认回到本地。

| 连接现象 | 优先查 | 当前不能推出 |
| --- | --- | --- |
| 超时 | 地址、端口、路由和对端是否有响应 | 不能凭超时判断账号或密码错误 |
| `Connection refused` | 目的地址是否正确、该端口是否在监听、是否有主动拒绝 | 不能凭这条认定 SSH 服务从未启用 |
| `Permission denied`（认证阶段） | 用户名、服务允许的认证方式、已授权凭据 | 不把某一种默认密码行为套到所有设备 |

## 2. 认识精简系统

内核负责调度、内存和设备等基础能力；发行版把内核、用户空间和系统管理工具打包；Shell 是负责理解命令的程序。OpenWrt 常由 BusyBox 提供一组精简工具，很多命令和桌面 Linux 同名，支持的参数可能不同。遇到 `invalid option` 时，看目标设备上该命令的帮助，别凭命令同名假定 GNU 选项都可用。

| 目录或状态 | 用途 | 观察方法 |
| --- | --- | --- |
| `/etc` | 系统配置；许多 OpenWrt 配置使用 `/etc/config` | `ls -ld /etc /etc/config` |
| `/proc` | 内核和进程的运行视图 | `head -n 5 /proc/meminfo`；它与普通磁盘文件不同 |
| `/tmp` | 临时文件；OpenWrt 中通常位于内存文件系统 | `df -h /tmp`；不把这里当唯一备份 |
| `/rom`、`/overlay` | 常见于采用只读镜像加可写层的 OpenWrt 安装 | 读 `mount`、`df -h` 再判断；只读层显示 100% 不代表可写层也满了 |

## 3. 检查记录够不够用

记录六项：`本地/远程 | 用户 | 当前目录 | 发行版 | 内核 | 命令及可用选项`。能根据这张卡解释：为什么同一条 `grep` 命令换机器可能报参数错误，以及一条相对路径在当前会话会落到哪个目录。真实主机名、地址和账号只留在自己有权限查看的记录中。

参考：[OpenSSH 客户端手册](https://man.openbsd.org/ssh)、[主机密钥检查选项](https://man.openbsd.org/ssh_config#StrictHostKeyChecking)、[BusyBox 命令手册](https://busybox.net/BusyBox.html)。回到[快通目录](README.md)。
