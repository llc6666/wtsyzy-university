# C++ 学习笔记

这里收录 69 篇原创学习笔记和六个可独立编译的代码示例。内容面向 C++ 入门到 STL、基础数据结构和基础算法，并包含 C 语言迁移所需的固定宽度整数练习。

## 阅读顺序

1. `01-基础语法`：控制流、数组、字符串、类型与运算符。
2. `02-函数与对象`、`03-指针与链表`：函数返回、对象生命周期、空指针、链表和队列。
3. `04-输入输出`、`05-数据结构`：格式化、编码、队列与一个 DSP 场景。
4. `06-STL`：容器、头文件、排序和优先队列。
5. `07-基础算法`：二分查找的区间不变量、二分答案、值域枚举和两道 Codeforces 题的建模过程。
6. `学习方法`：如何写可复用笔记，以及如何确认编译器与语言标准。
7. [算法学习闭环](../学习方法/算法学习闭环：从单题解出到同类迁移.md)：从单题实现推进到变式、边界测试和间隔重写。
