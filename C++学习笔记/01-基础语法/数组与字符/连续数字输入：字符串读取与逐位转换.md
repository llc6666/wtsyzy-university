# 连续数字输入：字符串读取与逐位转换

## 一句话结论

输入 `88005553535123456` 这类没有分隔符的数字串时，应先按字符串读取，再用 `ch - '0'` 把每个数字字符转换成一个 `int`，不要先把整串转换成整数。

## 为什么不能直接读成整数

```cpp
long long x;                         // long long 也有表示范围限制
std::cin >> x;                       // 直接读取整串数字
```

当数字串长度可能达到 300000 位时，它远远超过 `int`、`long long` 甚至常见浮点类型的表示能力。字符串可以保存这串数字的字符内容，而且前导零也不会丢失。

## 使用 `std::string` 和 `std::vector<int>`

```cpp
#include <iostream>                  // 提供 std::cin 和 std::cout
#include <string>                    // 提供 std::string
#include <vector>                    // 提供 std::vector

int main() {
    std::string s;                   // 保存连续输入的数字字符
    std::cin >> s;                   // 读取没有空格分隔的一串数字

    std::vector<int> digits;         // 保存转换后的数字值
    digits.reserve(s.size());       // 预留空间，减少扩容次数

    for (std::size_t i = 0; i < s.size(); ++i) { // 逐个访问每个数字字符
        int digit = s[i] - '0';      // 将字符数字转换为 0 到 9 的整数
        digits.push_back(digit);     // 把当前数字放入数组对应位置
    }

    for (std::size_t i = 0; i < digits.size(); ++i) { // 遍历转换后的数组
        std::cout << digits[i] << ' '; // 输出每个位置保存的整数
    }

    std::cout << '\n';              // 输出换行
    return 0;                        // 程序正常结束
}
```

输入：

```text
88005553535123456
```

得到的数组内容为：

```text
[8, 8, 0, 0, 5, 5, 5, 3, 5, 3, 5, 1, 2, 3, 4, 5, 6]
```

对应关系是：

```text
s[0]       -> '8' -> 8
s[1]       -> '8' -> 8
s[2]       -> '0' -> 0
```

## 输入长度最多为 300000

如果题目保证数字串长度不超过 300000，可以直接使用：

```cpp
std::string s;                       // string 可以保存整串字符
std::cin >> s;                       // 读取数字串
```

然后通过：

```cpp
s.size()                             // 获取实际输入长度
```

得到有效数字个数。数组下标范围是：

```text
0 到 s.size() - 1
```

## 只需要字符时，不必转换

如果后续只需要判断或输出数字字符，可以直接使用字符串：

```cpp
for (std::size_t i = 0; i < s.size(); ++i) { // 逐个遍历字符
    std::cout << s[i] << ' ';                // 直接输出字符，不转换为整数
}
```

只有在需要进行数值运算时，才转换为：

```cpp
int digit = s[i] - '0';                // 得到数字值 0 到 9
```

## 输入中可能有空格或换行

如果输入形式是：

```text
8 8 0 0 5 5
```

每个数字之间有空格，可以直接逐个读取整数：

```cpp
#include <iostream>                  // 提供标准输入输出
#include <vector>                    // 提供 vector

int main() {
    int n;                           // 保存数字个数
    std::cin >> n;                   // 读取数字个数

    std::vector<int> digits(n);      // 创建 n 个整数位置

    for (int i = 0; i < n; ++i) {    // 按位置读取 n 个数字
        std::cin >> digits[i];       // 保存当前输入数字
    }

    return 0;                        // 程序正常结束
}
```

连续输入和带空格输入是两种不同格式：

| 输入形式 | 读取方法 |
| --- | --- |
| `88005553535123456` | `std::string` 后逐字符转换 |
| `8 8 0 0 5 5` | `std::cin` 循环读取 `int` |

## 检查输入是否确实为数字

如果输入可能包含字母或其他字符，可以先检查范围：

```cpp
for (std::size_t i = 0; i < s.size(); ++i) { // 逐个检查输入字符
    if (s[i] < '0' || s[i] > '9') {           // 判断是否不在数字字符范围
        std::cout << "输入包含非数字字符\n"; // 报告非法输入
        return 0;                             // 发现错误后结束程序
    }
}
```

也可以使用 `<cctype>` 的 `std::isdigit`，但传入普通 `char` 时应先转换为 `unsigned char`。对于只处理 ASCII 数字的入门题，直接判断 `'0' <= ch && ch <= '9'` 更直观。

## 常见误区

1. 用 `int` 或 `long long` 保存最多 300000 位的整串数字，会发生溢出。
2. 直接写 `s[i]` 并当作数字使用；它得到的是字符编码，必须写 `s[i] - '0'`。
3. 用 `int a[300000]` 却只读入了实际长度，后续遍历整个数组会处理未使用位置；应记录 `s.size()`。
4. 题目要求保留前导零时，不能先转成整数，因为整数表示会丢失前导零。
5. 输入有空格时仍按“连续数字串”处理，实际读取结果会与预期不同。
