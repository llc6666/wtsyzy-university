# 题面：链表（火车路线）

> 来源：exercism/c 仓库 `exercises/practice/linked-list`（MIT 许可）。本文为中文译写，英文原件未保留。

你的团队决定用**双向链表**来表示时刻表里的每一条火车路线。路线上的每个车站是链表里的一个节点。

不需要考虑到站和发车时间，每个车站只用一个数字表示。

路线可以延长：在开头或末尾加车站。
路线也可以缩短：从开头或末尾去掉车站。

有时某个车站会关闭，这种情况下要把这个车站从路线中移除，即使它不在开头或末尾。

一条路线的「长度」不是按行驶距离算的，而是按**停靠多少个车站**算的。

## 链表是什么

链表是计算机科学里的基础数据结构，经常用来实现别的数据结构。

顾名思义，它是一串「节点」连起来的列表，每个节点连着它相邻的节点。

- **单向链表**：每个节点只连向它后面的那个节点
- **双向链表**：每个节点既连向前一个，也连向后一个
