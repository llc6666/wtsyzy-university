# 桶排序：按值域分桶后排序

## 什么时候用

数据能映射到有限连续区间且分布较均匀时。例如 `0..1` 的浮点数。它适合学习“先分治数据，再处理局部”的思路；通用数组排序优先 `std::sort`。

## 机制

先把每个值映射到桶编号，再分别排序桶内元素，最后按桶编号从小到大拼接。若数据落在 `[0, 1]`，用 `int(x * bucket_count)` 可以得到桶编号，但 `x == 1.0` 时会越过最后一个桶，所以必须截断到 `bucket_count - 1`。

## 最小可运行示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

void bucket_sort(std::vector<double>& a) {
    const int bucket_count = 5;
    std::vector<std::vector<double>> buckets(bucket_count);

    for (double x : a) {
        int index = std::min(bucket_count - 1, static_cast<int>(x * bucket_count));
        buckets[index].push_back(x);
    }

    int pos = 0;
    for (auto& bucket : buckets) {
        std::sort(bucket.begin(), bucket.end());
        for (double x : bucket) a[pos++] = x;
    }
}

int main() {
    std::vector<double> a = {0.42, 0.05, 0.91, 0.18, 0.73, 1.0};
    bucket_sort(a);
    for (double x : a) std::cout << x << ' ';
}
```

预期输出：

```text
0.05 0.18 0.42 0.73 0.91 1
```

## 如何验证

把 `1.0` 保留在输入中。若删除 `std::min`，程序会尝试访问第 6 个桶而只有 5 个桶，属于越界。再把多数输入改成 `0.99` 附近，观察它们都进入同一个桶，桶排序就接近对一个大桶做普通排序。

## 复杂度与边界

- 分布均匀且桶数合适时，平均可接近 `O(n + bucket_count)` 加上桶内排序成本。
- 最坏情况：所有元素进同一桶，复杂度由桶内排序决定，不能承诺线性时间。
- 上例只接受 `[0, 1]`。超出范围应先拒绝输入或定义新的映射规则。
- 需要额外桶空间；桶内使用的 `std::sort` 不稳定。
