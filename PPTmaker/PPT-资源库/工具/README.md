# PPTmaker 工具

## 适用范围

两个 PowerShell 脚本面向已经从官方项目获取本地素材包的使用者：

- `生成图标索引.ps1`：扫描本地 SVG，生成可搜索的相对路径索引。
- `核验资源库.ps1`：检查治理文件、素材文件和许可证文件是否同时存在。

公开版不带第三方素材，因此直接运行核验脚本会提示“尚未发现素材”。这表示公开版边界生效，不是脚本故障。

## 使用顺序

1. 阅读 `00-治理/素材许可证总表.csv`，确定官方来源和许可证。
2. 将具体素材包放入对应目录，并保留原项目许可证。
3. 运行两个脚本。
4. 再按 `30-制作规范/大学PPT生产规范.md` 完成页面和导出验收。

脚本不会上传素材、修改源文件或替代版权判断。
