# 字符与数字转换：字母和数字字符

## 一句话结论

字符 `'5'` 和整数 `5` 不是同一个东西。数字字符转换为对应数值时，使用：

```cpp
int digit = ch - '0';
```

前提是 `ch` 确实是 `'0'` 到 `'9'` 之间的数字字符。

## 数字字符转整数

```cpp
char ch = '7';
int number = ch - '0';

std::cout << number; // 7
```

原理是数字字符在字符编码中按顺序排列：

```text
'0' - '0' = 0
'1' - '0' = 1
'2' - '0' = 2
...
'9' - '0' = 9
```

注意：

```cpp
char ch = '7';
```

`ch` 保存的是字符 `'7'`，不是整数 `7`。直接写：

```cpp
int number = ch;
```

得到的是字符编码值，而不是数字 7。

## 转换前先判断是否为数字字符

```cpp
#include <cctype>

char ch = '7';

if (std::isdigit(static_cast<unsigned char>(ch))) {
    int number = ch - '0';
}
```

`std::isdigit` 用于判断字符是否为十进制数字字符。不要对任意负值 `char` 直接调用 `<cctype>` 中的分类函数；传入 `unsigned char` 转换后的值更稳妥。

## 整数转数字字符

如果整数范围是 `0` 到 `9`：

```cpp
int number = 7;
char ch = '0' + number;

std::cout << ch; // 7
```

必须保证 `number` 在 `0` 到 `9` 之间：

```cpp
if (number >= 0 && number <= 9) {
    char ch = static_cast<char>('0' + number);
}
```

如果要把任意整数转换成字符串，应使用：

```cpp
#include <string>

auto text = std::to_string(12345);
```

`'0' + number` 只适合生成一个数字字符，不适合处理 `10`、`123` 等多位数。

## 常用 ASCII 值

ASCII 是 7 位字符编码，共有 128 个编码值，范围是 `0` 到 `127`。其中 `0` 到 `31` 以及 `127` 是控制字符，`32` 到 `126` 主要是可打印字符。

| 字符或范围 | 十进制 | 十六进制 | 用途 |
| --- | ---: | ---: | --- |
| `\0` / NUL | 0 | `0x00` | C 风格字符串结束标记常用此值 |
| `\t` / TAB | 9 | `0x09` | 水平制表 |
| `\n` / LF | 10 | `0x0A` | 换行 |
| `\r` / CR | 13 | `0x0D` | 回车 |
| `' '` 空格 | 32 | `0x20` | 空格 |
| `'0'` 到 `'9'` | 48 到 57 | `0x30` 到 `0x39` | 数字字符 |
| `'A'` 到 `'Z'` | 65 到 90 | `0x41` 到 `0x5A` | 大写英文字母 |
| `'a'` 到 `'z'` | 97 到 122 | `0x61` 到 `0x7A` | 小写英文字母 |
| `DEL` | 127 | `0x7F` | 删除控制字符 |

## 如何在 C++ 中查看字符编码

```cpp
#include <iostream>

int main() {
    char ch = 'A';

    std::cout << static_cast<int>(ch) << '\n';
    // 常见 ASCII 环境输出 65
}
```

`char` 输出时通常显示字符；转换为 `int` 后才会按数值输出：

```cpp
std::cout << ch << '\n';                  // A
std::cout << static_cast<int>(ch) << '\n'; // 65
```

## 常用规律

```cpp
'A' + 32 == 'a' // 常见 ASCII 环境下成立
'a' - 'A' == 32
'9' - '0' == 9
```

不过实际代码中不要靠手写 `32` 进行大小写转换，优先使用 `std::tolower`、`std::toupper`，并注意它们的输入要求。字符字面量也比直接写编码数字更清楚：

```cpp
if (ch >= '0' && ch <= '9') {
    int number = ch - '0';
}
```

C++ 的基本字符集保证这些英文字母、数字和标点字符存在，但具体执行字符集的数值编码由实现决定。表中的十进制值是 ASCII 环境下的值，不应把它们当成所有编码（例如 UTF-8 中文字符）的通用编号。
## 大小写字母的范围

在常见 ASCII 编码环境中：

| 类型 | 字符范围 | 十进制编码范围 |
| --- | --- | ---: |
| 大写字母 | `'A'` 到 `'Z'` | 65 到 90 |
| 小写字母 | `'a'` 到 `'z'` | 97 到 122 |

代码中建议写字符字面量，不要直接写 65、90、97、122：

```cpp
if (ch >= 'A' && ch <= 'Z') {
    // ch 是大写英文字母
}

if (ch >= 'a' && ch <= 'z') {
    // ch 是小写英文字母
}
```

判断是否为英文字母：

```cpp
if ((ch >= 'A' && ch <= 'Z') ||
    (ch >= 'a' && ch <= 'z')) {
    // ch 是大写或小写英文字母
}
```

如果要按当前字符区域判断字母类别，使用 `<cctype>`：

```cpp
#include <cctype>

if (std::isalpha(static_cast<unsigned char>(ch))) {
    // ch 被当前字符分类规则视为字母
}
```

`std::isupper`、`std::islower`、`std::isalpha` 的判断可能受 locale 影响；`'A'` 到 `'Z'`、`'a'` 到 `'z'` 的写法针对的是英文字母范围。C++ 标准规定基本字符集包含 26 个大写和 26 个小写字母，但普通执行字符集的具体编码由实现决定；因此不要把“65 到 90、97 到 122”当作所有字符集的普遍规律。
## 字母转换为序号

在常见 ASCII 语境下：

```cpp
char ch = 'C';
int index = ch - 'A'; // 2，表示 C 是从 0 开始的第 3 个大写字母
```

小写字母：

```cpp
char ch = 'c';
int index = ch - 'a'; // 2
```

转换前应先确认大小写和范围：

```cpp
if (ch >= 'A' && ch <= 'Z') {
    int index = ch - 'A';
}
```

如果要统一大小写，可以使用：

```cpp
#include <cctype>

char lower = static_cast<char>(std::tolower(
    static_cast<unsigned char>(ch)
));
```

## 常见错误

### 把字符和整数混淆

```cpp
char ch = '5';

int a = ch - '0'; // 5
int b = ch;       // 字符编码值，不是 5
```

### 没有检查输入范围

```cpp
char ch = 'x';
int number = ch - '0'; // 没有意义，不是合法数字转换
```

正确：

```cpp
if (ch >= '0' && ch <= '9') {
    int number = ch - '0';
}
```

### 误以为 `int('5')` 能完成转换

```cpp
// int number = int('5');
```

这只是把字符类型转换为整数类型，结果通常是字符编码值。要获得数字 5，应写：

```cpp
int number = '5' - '0';
```

## 使用规则

1. `'5'` 是字符，`5` 是整数，两者类型和语义不同。
2. 数字字符转数值：`ch - '0'`。
3. 数值转单个数字字符：`'0' + number`，并保证 `number` 在 `0` 到 `9`。
4. 多位整数转文本：使用 `std::to_string`。
5. 字母序号转换前检查大小写和范围。
6. 使用 `<cctype>` 函数时，传入 `unsigned char` 转换后的值更稳妥。
