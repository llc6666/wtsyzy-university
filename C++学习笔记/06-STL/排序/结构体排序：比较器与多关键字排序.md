# 结构体排序：比较器与多关键字排序

## 一句话结论

结构体适合表达一条完整记录；排序时通过比较器明确“先按哪个字段、使用升序还是降序”。

## 头文件

```cpp
#include <algorithm>  // std::sort、std::stable_sort
#include <iostream>   // std::cout
#include <string>     // std::string
#include <vector>     // std::vector
```

竞赛中可以见到：

```cpp
#include <bits/stdc++.h>
```

但它不是 C++ 标准头文件。学习和可移植代码应直接包含实际使用的标准头文件。

## 基本示例

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

struct Record {
    int id;
    int score;
    std::string name;
};

int main() {
    std::vector<Record> arr;
    arr.push_back(Record{3, 85, "Alice"});
    arr.push_back(Record{1, 92, "Bob"});
    arr.push_back(Record{2, 85, "Cara"});

    std::sort(arr.begin(), arr.end(),
        [](const Record& a, const Record& b) {
            return a.score > b.score;
        });

    for (std::vector<Record>::const_iterator it = arr.begin();
         it != arr.end(); ++it) {
        std::cout << it->id << ' '
                  << it->score << ' '
                  << it->name << '\n';
    }
}
```

比较器中的：

```cpp
return a.score > b.score;
```

表示成绩高的记录排在前面，也就是按 `score` 降序排列。

## 比较器到底表达什么

比较器接收两个对象 `a` 和 `b`，返回：

> `a` 是否应该排在 `b` 前面。

升序：

```cpp
return a.score < b.score;
```

降序：

```cpp
return a.score > b.score;
```

比较器应构成严格弱序，不能随意写成 `<=`。`std::sort` 的比较器要求满足相应的排序关系；否则结果可能不正确。

## 多关键字排序

先按成绩降序，成绩相同后按 `id` 升序：

```cpp
std::sort(arr.begin(), arr.end(),
    [](const Record& a, const Record& b) {
        if (a.score != b.score) {
            return a.score > b.score;
        }
        return a.id < b.id;
    });
```

执行逻辑：

1. 先比较 `score`。
2. 成绩不同，成绩高者在前。
3. 成绩相同，再比较 `id`。
4. `id` 小者在前。

多关键字排序的结构通常是：

```cpp
if (第一关键字不同) {
    return 第一关键字的排序规则;
}
return 第二关键字的排序规则;
```

如果还有第三关键字，继续嵌套判断。

## 用普通函数作为比较器

旧版编译器不支持 lambda 时，可以写普通函数：

```cpp
bool cmp(const Record& a, const Record& b) {
    if (a.score != b.score) {
        return a.score > b.score;
    }
    return a.id < b.id;
}

std::sort(arr.begin(), arr.end(), cmp);
```

这种写法适合旧版 Dev-C++ 或 C++03 环境。

## 重载 `operator<`

如果某种排序规则是这个结构体的默认排序规则，可以重载 `operator<`：

```cpp
struct Record {
    int id;
    int score;
    std::string name;

    bool operator<(const Record& other) const {
        if (score != other.score) {
            return score > other.score;
        }
        return id < other.id;
    }
};
```

之后可以直接写：

```cpp
std::sort(arr.begin(), arr.end());
```

这里虽然函数名是 `operator<`，但内部写 `score > other.score`，因为它表达的是：

> 当前对象是否应该排在 `other` 前面。

如果同一种结构体经常需要不同排序方式，比较器通常比重载 `operator<` 更灵活，也更不容易把某一种业务排序规则绑定成全局默认规则。

## 稳定排序

如果成绩相同的记录需要保持输入时的原始顺序，可以使用：

```cpp
std::stable_sort(arr.begin(), arr.end(),
    [](const Record& a, const Record& b) {
        return a.score > b.score;
    });
```

`std::stable_sort` 会保持等价元素的相对顺序。

但如果已经明确写出第二关键字，例如：

```cpp
if (a.score != b.score) {
    return a.score > b.score;
}
return a.id < b.id;
```

通常不再依赖稳定性来解决并列顺序。

## 从二维数组转换为结构体

如果原始数据来自二维数组：

```cpp
int raw[3][2] = {
    {3, 85},
    {1, 92},
    {2, 85}
};
```

可以转换为结构体数组：

```cpp
std::vector<Record> arr;

for (int i = 0; i < 3; ++i) {
    Record r;
    r.id = raw[i][0];
    r.score = raw[i][1];
    r.name = "";
    arr.push_back(r);
}
```

之后使用结构体字段排序：

```cpp
std::sort(arr.begin(), arr.end(),
    [](const Record& a, const Record& b) {
        return a.score > b.score;
    });
```

字段有名字后，代码比 `raw[i][0]`、`raw[i][1]` 更容易阅读和维护。

## 常见误区

1. 比较器返回“两个元素是否相等”，这是错误方向；它应判断前者是否排在后者前面。
2. 多关键字排序忘记处理相等情况，会导致第二关键字失效。
3. 把 `operator<` 误解为必须升序；它实际表达的是“是否应该排在前面”。
4. 需要稳定性却使用 `std::sort`，相等元素的原始顺序不应依赖普通 `sort`。
5. 直接使用 `bits/stdc++.h`，代码会失去跨编译器可移植性。
