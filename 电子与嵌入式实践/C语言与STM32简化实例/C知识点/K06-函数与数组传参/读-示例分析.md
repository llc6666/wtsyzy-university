## 一、`clock`：用指针参数带出两个结果

两个观察：

1. **函数要改两个值，就收两个指针**。这是 C 里「返回多个结果」的标准做法，返回值留给错误码或状态
2. 处理负数分钟用的是 `while (*minute < 0) *minute += 60;`，而不是 `(*minute % 60 + 60) % 60`。原因：C 里负数取模的结果符号跟着实现走，用循环加虽然笨但**结果确定**

## 读码小结

1. 看到函数签名，先分清每个参数是「输入」还是「输出」
2. 输出型参数通常是指针，且名字常带 `out_` 前缀
3. 看到 `static` 的函数，它就是这个文件的内部实现
