# 题面：二进制转十进制

> 来源：exercism/c 仓库 `exercises/practice/binary`（MIT 许可）。本文为中文译写，英文原件未保留。

把用字符串表示的二进制数（例如 `'101010'`）转换成对应的十进制数，用基本方法实现。

实现二进制到十进制的转换：给定二进制字符串输入，输出十进制数，并且要能处理非法输入。

## 注意

- 转换过程自己实现，不要调用现成的转换函数

## 关于二进制（基 2）

十进制是基 10 系统。数字 23 可以理解为 10 的幂的线性组合：

- 最右边的数字乘 10⁰ = 1
- 下一个数字乘 10¹ = 10
- ……第 n 位乘 10ⁿ⁻¹
- 全部相加

所以 `23 => 2*10¹ + 3*10⁰ => 20 + 3 => 23`（十进制）

二进制同理，只是用的是 2 的幂：

`101 => 1*2² + 0*2¹ + 1*2⁰ => 4 + 0 + 1 => 5`（十进制）
