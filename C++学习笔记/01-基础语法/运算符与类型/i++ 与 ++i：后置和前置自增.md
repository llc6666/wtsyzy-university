# i++ 与 ++i：后置和前置自增

## 一句话结论

`i++` 和 `++i` 都会让 `i` 增加 1。区别只在于整个表达式“交出去的值”：`i++` 先交出旧值再加 1；`++i` 先加 1再交出新值。

## 单独写成一行时

```cpp
int i = 3;
i++;  // i 变为 4

++i;  // i 变为 5
```

单独作为一条语句时，最终效果相同：变量都增加 1。

## 用在赋值表达式中时

```cpp
int i = 3;
int a = i++; // a 得到旧值 3，随后 i 变为 4

int j = 3;
int b = ++j; // j 先变为 4，b 得到新值 4
```

用表格记忆：

| 写法 | 变量最终值 | 表达式得到的值 |
| --- | --- | --- |
| `i++` | `i + 1` | 增加前的旧值 |
| `++i` | `i + 1` | 增加后的新值 |

## 在 `for` 循环中该写哪个

```cpp
for (int i = 0; i < 5; ++i) {
    std::cout << i << '\n';
}
```

对于内置整数 `int`，在 `for` 的第三部分写 `i++` 或 `++i`，循环结果通常完全相同，因为这里不使用该自增表达式的值。

```cpp
for (int i = 0; i < 5; i++) {
}

for (int i = 0; i < 5; ++i) {
}
```

两者都能正确循环 5 次。学习阶段统一使用 `++i` 可以表达“本轮结束后把计数器加一”；但更重要的是理解，不是背诵哪一种绝对更快。

## 不要写难以判断顺序的复杂表达式

```cpp
// 不推荐
array[i++] = i;
```

即使某些语言版本对部分求值顺序已有规定，这类代码仍要求读者同时追踪 `i` 的旧值、新值和表达式求值顺序。拆开写更清楚：

```cpp
array[i] = i;
++i;
```

当一个变量既被修改又在同一复杂表达式中多次使用时，优先拆成多行。

## 自增指针时的含义

自增不只用于整数。指针自增表示移到同类型数组的下一个元素：

```cpp
int values[3]{10, 20, 30};
int* p = values;

++p; // p 现在指向 values[1]
```

它只适用于同一数组范围内的有效移动。链表中的 `Node*` 不应使用 `++p` 走向下一个节点；链表节点并不保证连续存放，应写：

```cpp
p = p->next;
```

## 使用规则

1. 单独一行时，`i++` 与 `++i` 的最终变量结果相同。
2. 需要使用表达式结果时，先问自己需要旧值还是新值。
3. `for` 的计数步骤中，`i++` 和 `++i` 对 `int` 的循环结果相同。
4. 避免在同一复杂表达式中反复读写同一个自增变量。
5. 指针 `++p` 用于数组的连续元素；链表前进用 `p = p->next`。
