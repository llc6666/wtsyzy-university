# 课程地图与学期规划

## 结论

课程规划的起点是正式培养要求和先修关系，不是课程名气、短期焦虑或他人经验。把课程、能力和学期放进同一张表，才能看见真正的约束。

## 课程地图的字段

| 字段 | 作用 |
| --- | --- |
| 课程性质 | 区分必修、选修、实践或其他要求 |
| 学分与预估负荷 | 判断时间成本，避免同一学期过载 |
| 开课时间与先修关系 | 找出顺序约束和补救窗口 |
| 能力目标 | 说明课程为何重要 |
| 考核方式 | 决定学习节奏与复习策略 |

课程回答“学什么”，能力目标回答“为什么学”，学期安排回答“何时投入”。三者缺一，计划就容易变成课程清单或空泛目标。

## 制定顺序

1. 找到适用于自己的最新正式文件和当期通知。
2. 先排固定要求、先修链和高风险课程。
3. 估计每门课的总负荷，而非只看学分。
4. 再安排选修、项目和探索任务，给突发情况留出余量。
5. 学期结束后复盘实际负荷、成绩和先修缺口，更新下一张地图。

## 边界

- 不同学校和年份的培养要求不能互相替代。
- 他人的选课经验只能提供线索，不能取代当前正式规则。
- 规划降低信息缺失，不能代替持续练习和教师要求。

## 自检

- 每门关键课程是否有对应的能力目标？
- 是否核验了先修、冲突和当期规则？
- 是否为难课和异常情况预留了时间？
- 学期结束后是否比较了计划与实际结果？
