# 快速排序

步骤：

1. 选择分界值 `pivot`。
2. 分区，使左侧不大于分界值、右侧不小于分界值。
3. 递归处理左右区间。

```cpp
void quick_sort(std::vector<int>& a, int left, int right) {
    if (left >= right) {
        return;
    }

    int i = left - 1;
    int j = right + 1;
    int pivot = a[left + (right - left) / 2];

    while (i < j) {
        do {
            ++i;
        } while (a[i] < pivot);

        do {
            --j;
        } while (a[j] > pivot);

        if (i < j) {
            std::swap(a[i], a[j]);
        }
    }

    quick_sort(a, left, j);
    quick_sort(a, j + 1, right);
}
```

快速排序平均 `O(n log n)`，但分区极不平衡时可能退化到 `O(n^2)`。分界值选两端、重复元素很多或数据已经有序时，要特别注意边界和递归深度。实际代码通常直接使用 `std::sort`。
