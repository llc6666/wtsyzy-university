## eliuds-eggs

- 位置：`exercism-c/c-main/exercises/practice/eliuds-eggs/` （原始目录路径，随库搬运后失效；题面与参考解副本见本知识点 README 的素材表）
- 接口：**头文件是空的**，函数签名要自己定（这本身就是 C 的练习：先想清楚入参和返回类型再写）
- 题面要点：统计二进制中 1 的个数；明确禁止使用标准库的位计数功能
- 两种思路：逐位测试 `n & (1u << i)`；或 `n &= n - 1` 每次消掉最低位的 1，循环次数等于 1 的个数

### 验收标准（用例表 + 五类边界）

- 签名（官方）：`unsigned int egg_count(unsigned int value)`
- 用例表：

| `value` | 期望 |
| --- | --- |
| `0` | 0 |
| `1` | 1 |
| `0x10`（16） | 1 |
| `0x3`（0b11） | 2 |
| `0xFF` | 8 |
| `0xFFFFFFFF` | 32 |

- 五类边界：

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `value = 0` | 0，且不能死循环 |
| 最小 | `value = 1` | 1 |
| 最大 | `0xFFFFFFFF` | 32（32 位全 1） |
| 相等 | 相邻两个 1 位（`0b11`） | 2，验证不是只数最低位 |
| 非法 | 不得调用标准库的位计数功能 | 自己实现；用 `int` 移位到符号位会出错，用 `unsigned` |

- 不变量：返回值落在 0–32；不修改输入；无符号右移，不做算术右移

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**：这一题本身就是最优解之争，比较的是两种做法的循环次数（固定 32 次 vs 等于 1 的个数）
3. **哪里最容易错**：`n` 为负数时的右移；用 `int` 移位到符号位

## allergies

- 位置：`exercism-c/c-main/exercises/practice/allergies/` （原始目录路径，随库搬运后失效；题面与参考解副本见本知识点 README 的素材表）
- 接口：`bool is_allergic_to(allergen_t allergen, unsigned int score)`、`allergen_list_t get_allergens(unsigned int score)`
- 题面要点：8 个过敏原对应 8 个位；分数里超出范围的位（256、512…）要**忽略**
- 这一题直接对应「位标志集合」，和 GPIO 多引脚组合是同一回事

### 验收标准（用例表 + 五类边界）

- 签名（官方）：`bool is_allergic_to(allergen_t allergen, unsigned int score)`、`allergen_list_t get_allergens(unsigned int score)`
- 位序：`eggs=0, peanuts=1, shellfish=2, strawberries=3, tomatoes=4, chocolate=5, pollen=6, cats=7`
- 用例表：

| `score` | 期望 |
| --- | --- |
| `0` | 无任何过敏，`count = 0` |
| `1` | eggs |
| `34`（2 + 32） | peanuts、chocolate；eggs 为 false |
| `255` | 全部 8 项，`count = 8` |
| `257`（1 + 256） | 只有 eggs（256 被忽略） |

- 五类边界：

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `score = 0` | `count = 0`，数组全 false |
| 最小 | `score = 1` | 只有 eggs |
| 最大 | `score = 255` | 8 项全中，`count = 8` |
| 相等 | `score = 257` 与 `score = 1` | 结果相同（第 8 位及以上忽略） |
| 非法 | 传入超出 `ALLERGEN_COUNT` 的枚举值 | 不越界访问 `allergens[]` 数组 |

- 不变量：`count` 必须等于数组中 `true` 的个数；`get_allergens` 与 `is_allergic_to` 对同一 score 的判断必须一致

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**
3. **哪里最容易错**：忽略高位（只处理 0–7 位）；`count` 的统计容易漏

## binary

- 位置：`exercism-c/c-main/exercises/practice/binary/` （原始目录路径，随库搬运后失效；题面与参考解副本见本知识点 README 的素材表）
- 接口：`int convert(const char *input)`，非法输入返回 `INVALID`（即 -1）
- 题面要点：二进制字符串转十进制，自己实现，不得调用转换函数
- 核心手法：`result = result * 2 + (bit)`，等价于左移加位

### 验收标准（用例表 + 五类边界）

- 签名（官方）：`int convert(const char *input)`；非法输入返回 `INVALID`（即 -1）
- 用例表（取自官方测试）：

| `input` | 期望 |
| --- | --- |
| `"0"` | 0 |
| `"1"` | 1 |
| `"10"` | 2 |
| `"11"` | 3 |
| `"100"` | 4 |
| `"1001"` | 9 |

- 五类边界：

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `""` | `INVALID`（-1） |
| 最小 | `"0"` | 0（不是 -1，0 是合法值） |
| 最大 | 31 个 `"1"` | 不超过 `int` 表示范围；超长输入按非法或溢出处理需明确定义 |
| 相等 | `"01"` 与 `"1"` | 都等于 1（前导零不影响） |
| 非法 | `"2"`、`"10a"`、`"carrot"` | `INVALID` |

- 不变量：非法输入一律返回 -1；不修改输入字符串；空指针输入不得解引用

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**
3. **哪里最容易错**：遇到非 0/1 字符要判非法；空字符串；结果溢出

## secret-handshake

- 位置：`exercism-c/c-main/exercises/practice/secret-handshake/` （原始目录路径，随库搬运后失效；题面与参考解副本见本知识点 README 的素材表）
- 接口：`const char **commands(size_t number)`
- 题面要点：低 5 位分别对应 wink / double blink / close your eyes / jump / 反转顺序
- 注意返回值是 `const char **`：**不能返回局部数组的地址**，需要用静态数组或调用方提供的空间

### 验收标准（用例表 + 五类边界）

- 签名（官方）：`const char **commands(size_t number)`
- 位序：`1=wink`、`2=double blink`、`4=close your eyes`、`8=jump`、`16=反转顺序`
- 用例表：

| `number` | 期望序列 |
| --- | --- |
| `1` | wink |
| `4` | close your eyes |
| `3` | wink, double blink |
| `19`（10011） | double blink, wink |
| `26`（11010） | jump, double blink |
| `31` | jump, close your eyes, double blink, wink |

- 五类边界：

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `number = 0` | 空序列 |
| 最小 | `number = 1` | 只含 wink |
| 最大 | `number = 31` | 四项全在，且顺序反转 |
| 相等 | `number = 16` | 空序列（反转空序列仍是空） |
| 非法 | `number > 31` | 题面限定 1–31；若处理更大值，按低 5 位取值并在注释里写明 |

- 不变量：返回数组容量固定为 4，未使用的位置为 NULL；**返回的地址在函数返回后仍然有效**（静态数组或动态分配，不能是局部数组）；若用 `calloc` 分配，由调用方 `free`（官方参考解即如此）

### 复盘三问（做完填）

1. **为什么对**
2. **暴力做法为什么不行**
3. **哪里最容易错**：返回局部数组（悬空指针）；反转顺序时把字符串本身的顺序也改了（要改的是指针顺序）
