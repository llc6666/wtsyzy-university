# 百分比输出与小数位格式化

## 一句话结论

要把比例值 `0.1234` 输出成 `12.34%`，需要完成两件事：

1. 乘以 `100`，把比例转换为百分数数值。
2. 使用 `std::fixed << std::setprecision(2)`，固定保留两位小数。

```cpp
#include <iostream>
#include <iomanip>

int main() {
    double ratio = 0.1234;

    std::cout << std::fixed << std::setprecision(2)
              << ratio * 100 << "%\n";
}
```

输出：

```text
12.34%
```

`std::fixed` 固定使用小数形式，`std::setprecision(2)` 在固定格式下表示小数点后保留两位。`setprecision` 位于 `<iomanip>`，会设置流的精度参数。

## 比例值和百分数值要分清

```cpp
double ratio = 0.125;   // 比例形式，表示 12.5%
double percent = 12.5;  // 百分数形式，已经是 12.5
```

比例形式输出：

```cpp
std::cout << std::fixed << std::setprecision(2)
          << ratio * 100 << "%\n";
```

百分数形式输出：

```cpp
std::cout << std::fixed << std::setprecision(2)
          << percent << "%\n";
```

不要对已经是 `12.5` 的百分数再次乘以 `100`，否则会输出 `1250.00%`。

## `#include <iomanip>` 是什么

```cpp
#include <iomanip>
```

这是一条预处理指令，表示把标准库头文件 `<iomanip>` 提供的声明引入当前源文件。`iomanip` 可以理解为 **input/output manipulation**，即“输入输出格式控制”。它提供了许多流操纵器，例如：

```cpp
std::setprecision(2); // 设置浮点数精度
std::fixed;           // 使用固定小数格式
std::setw(10);        // 设置字段宽度
std::setfill('0');    // 设置填充字符
```

`std::setprecision` 在 `<iomanip>` 中声明；`std::fixed` 属于浮点输出格式控制。使用它们时，推荐写完整的 `std::` 前缀：

```cpp
#include <iostream>
#include <iomanip>

int main() {
    double ratio = 0.1234;

    std::cout << std::fixed
              << std::setprecision(2)
              << ratio * 100 << "%\n";
}
```

如果写了：

```cpp
std::cout << std::setprecision(2);
```

但没有：

```cpp
#include <iomanip>
```

编译器通常无法识别 `std::setprecision`。
## `fixed` 是什么意思

`fixed` 可以理解为“固定小数格式”。它要求浮点数使用普通的小数表示法输出，而不是根据数值大小自动切换为科学计数法；它设置的是输出流的浮点格式标志。

```cpp
#include <iostream>
#include <iomanip>

int main() {
    double a = 12.3456;
    double b = 0.0000123456;

    std::cout << std::fixed << std::setprecision(2)
              << a << '\n'
              << b << '\n';
}
```

输出效果类似：

```text
12.35
0.00
```

第二个数并非变成了 `0`，只是按照“小数点后两位”的显示规则被四舍五入显示为 `0.00`。`fixed` 改变的是**显示格式**，不会改变变量本身的数值。

与它相对的常见格式是：

```cpp
std::scientific;  // 科学计数法，例如 1.23e-05
std::defaultfloat; // 恢复默认浮点格式
```

因此：

```cpp
std::fixed << std::setprecision(2)
```

可以直接理解为：

> 用普通小数形式输出，并显示小数点后两位。
## `setprecision(2)` 为什么要配合 `fixed`

```cpp
std::cout << std::setprecision(2) << 12.3456;
```

不加 `fixed` 时，精度通常按有效数字处理；加上 `fixed` 后，才表示小数点后两位：

```cpp
std::cout << std::fixed << std::setprecision(2) << 12.3456;
```

输出：

```text
12.35
```

输出格式会按流状态持续影响后续浮点输出。如果只想影响一条输出，可以在之后恢复默认格式：

```cpp
std::cout << std::fixed << std::setprecision(2)
          << ratio * 100 << "%\n"
          << std::defaultfloat;
```

## 整数除法陷阱

错误：

```cpp
int finished = 1;
int total = 3;

double ratio = finished / total; // 先进行整数除法，结果为 0
```

正确：让至少一个操作数参与浮点除法：

```cpp
double ratio = static_cast<double>(finished) / total;

std::cout << std::fixed << std::setprecision(2)
          << ratio * 100 << "%\n";
```

输出：

```text
33.33%
```

## 完整示例：输入数量计算百分比

```cpp
#include <iostream>
#include <iomanip>

int main() {
    int success;
    int total;
    std::cin >> success >> total;

    if (total == 0) {
        std::cout << "无法计算\n";
        return 0;
    }

    double ratio = static_cast<double>(success) / total;

    std::cout << std::fixed << std::setprecision(2)
              << ratio * 100 << "%\n";
}
```

输入：

```text
1 3
```

输出：

```text
33.33%
```

## 直接输出 `bool` 的区别

如果计算结果本身是 `bool`：

```cpp
bool passed = true;
```

它不是百分比数值。若想输出通过率，需要统计通过数量和总数量：

```cpp
int passed = 8;
int total = 10;
double ratio = static_cast<double>(passed) / total;

std::cout << std::fixed << std::setprecision(2)
          << ratio * 100 << "%\n";
```

输出：

```text
80.00%
```

## 使用规则

1. 比例 `0.25` 转百分数要乘 `100`，结果为 `25.00%`。
2. 使用 `<iomanip>` 中的 `std::fixed` 和 `std::setprecision(2)`。
3. `fixed` 下的 `setprecision(2)` 表示小数点后两位。
4. 两个 `int` 相除前，至少把一个转换为 `double`。
5. 先确认变量存的是比例形式还是百分数形式，避免重复乘以 `100`。
6. 分母必须先判断是否为 `0`。
