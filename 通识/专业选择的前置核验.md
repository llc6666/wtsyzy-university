# 专业选择的前置核验

## 结论

在评价一个专业或考虑转向前，先核验培养内容、制度路径、个人适配和结果证据。专业选择是带约束的决策，不是一次标签判断。

## 四类证据

| 维度 | 需要核验的内容 |
| --- | --- |
| 培养内容 | 核心课程、学习方式、难点与先修关系 |
| 制度路径 | 调整方向、辅修或其他选择的条件、窗口与材料 |
| 个人适配 | 兴趣、基础、资源、时间与风险承受能力 |
| 结果证据 | 真实任务、作品、课程表现与公开去向信息 |

## 做法

1. 找到当前适用的正式培养文件和课程说明。
2. 记录核心课程、先修关系、考核方式和需要补足的基础。
3. 核验调整路径的条件、时间和材料，不把经验当规则。
4. 把访谈和案例标记为个体样本。
5. 用一个周期的小任务验证适配度。
6. 到复查时间后再决定继续、调整或转向。

## 边界

制度会变，旧资料不能替代最新文件。适配度也无法只靠阅读判断，必须在真实学习与任务中验证。任何调整路径都可能存在名额、成绩或时间限制。

## 自检

- 是否使用了当前正式来源？
- 是否区分了规则、案例和个人观点？
- 是否做过小规模验证？
- 是否准备了失败后的备选路径？
