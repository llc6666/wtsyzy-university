# 计算类课程复习：把素材、练习、错题与测评分层

## 何时使用

当你有很多题、讲义、错题和测评结果，却回答不清下面几个问题时使用：

- 这份材料只是收集过，还是已经独立做过？
- 这道题错在知识、判断、步骤、计算，还是根本没有留下记录？
- 下一轮应该补定理、练动作、换变式，还是先停止扩张题库？
- 一个分数能说明什么，不能说明什么？

这套方法适用于微积分、离散数学、物理推导、算法题等需要“理解、计算、推导、复现”的课程。它管理学习证据，不替代具体学科的教材、定理证明和教师反馈。

## 输入与目录结构

准备四类材料，并把它们分开放置：

| 层 | 保存什么 | 能回答的问题 | 不能回答的问题 |
| --- | --- | --- | --- |
| 素材库 | 讲义、教材章节、题目、公开资料 | 有哪些内容可读、可练 | 自己是否做过、是否会做 |
| 练习台账 | 每次实际尝试的题目、日期、结果、证据位置 | 哪些题真正练过、还缺哪些记录 | 是否已经掌握整类知识 |
| 错题与缺口卡 | 错因、失效前提、漏掉的步骤、修正动作、重做状态 | 具体错在哪里、下一次练什么 | 课程整体完成度 |
| 阶段测评 | 一份混合题或限时任务的结果 | 当前暴露了哪些断点 | 单凭一次分数证明已经掌握 |

目录可以按下面的最小结构建立：

```text
学习主题/
├─ 00-素材索引.md
├─ 01-练习台账.md
├─ 02-缺口与错题/
├─ 03-阶段测评/
└─ 04-主题总结.md
```

如果一个题目同时出现在素材库和错题本中，给不同集合加前缀，例如 `库-12`、`错-12`、`测-03`。编号相同不代表内容相同。记录引用时写完整前缀，避免后续复盘时把不同题目合并。

## 先固定五种状态

不要把“看过、做过、做对、能解释、能迁移”写成一个“已掌握”。至少分开记录：

1. **已收集**：文件或题目已经进入素材库。
2. **已尝试**：本人实际写过、算过或推过，并留下日期和结果。
3. **已完成**：本次答案达到当前任务要求，但还没有经过间隔重做。
4. **可复现**：关闭答案和旧稿后，能独立重建关键步骤，并能说明使用条件。
5. **可迁移**：换一种表面形式后仍能识别同一个底层动作，且能解释前提变化。

“读懂解析”最多证明你能跟随一条路线；“自述会做”可以作为线索，但不能替代作答记录。状态字段应记录证据，不记录情绪判断。

## 一轮复习的操作顺序

### 1. 先盘点，不要继续扩大题库

为每份材料建立索引，至少记录：

```text
材料编号：
来源类型：教材 / 讲义 / 自编题 / 公开题 / 测评
主题：
预计训练动作：
是否实际作答：是 / 否 / 无法确认
证据位置：
当前处理：保留 / 待练 / 已归档 / 待复核
```

先把“素材数量”和“已练数量”分开统计。题目很多并不代表练习量大，题目较少也不代表缺口少。

### 2. 用小型混合测评找断点

从不同章节或不同动作中抽取少量题目，先不看答案。每题只记录四件事：

- 是否能说清题目要求；
- 是否能选出所需定义、定理或公式；
- 是否能写出第一步；
- 卡住时属于哪一类缺口。

测评的作用是定位下一步，不是把一次得分写成能力结论。若题面来源、答案或评分标准不完整，标记证据不足，不据此推断掌握程度。

### 3. 把缺口归类，再选择补法

同样的“做错”对应的处理动作不同。使用下面的映射：

| 缺口类型 | 典型表现 | 下一步动作 |
| --- | --- | --- |
| 工具未掌握 | 不知道该用哪个定义或定理 | 回到最小定义，写出使用条件和一个反例 |
| 工具未触发 | 会相关方法，但第一步没有想到 | 做同一动作的两道不同表面题，专门练识别信号 |
| 检索方向反了 | 知道结论，却不知道怎样构造中间对象 | 从目标式倒推需要的对象，再检查每一步前提 |
| 条件门槛漏检 | 直接套公式，忽略连续性、可导性、定义域等条件 | 在草稿第一行写“使用条件清单”，逐项打勾 |
| 机械计算错误 | 方法路线正确，符号、系数、代入或边界出错 | 把整题拆成单独动作，增加具体的中间结果检查 |
| 形式与结论冲突 | 最终答案碰巧正确，但推导中有不能成立的等式 | 回到第一处不合法的变形，重写依据，不保留侥幸答案 |
| 只做未记录 | 记得自己做过，却找不到题目、过程或结果 | 补一行台账；无法恢复的内容标为“来源未提供完整记录” |

其中“工具未掌握”和“工具未触发”不能用同一套题补。前者需要补概念和条件，后者需要换题面练检索。

### 4. 为每个缺口建立一张卡

```text
缺口编号：
触发题目：
底层动作：
错误类型：工具未掌握 / 未触发 / 条件漏检 / 计算 / 记录缺失
第一处错误：
正确规则：
最小补充材料：
下一道变式改变什么：
重做日期：
重做状态：未开始 / 独立完成 / 仍需讲解
证据位置：
```

“这题粗心”“以后认真”不能作为修正规则。修正规则必须能指导下一次动作，例如“分段函数的分界点先分别代左右表达式，再计算两侧差商”，而不是“注意连续性”。

### 5. 按底层动作安排变式

变式要保留要练的动作，同时改变至少一个表面条件：

- 改变函数、数据或符号，但保留同一判据；
- 改变问法，从求值改为判断条件；
- 改变区间、边界或初始状态；
- 把单步题改成需要先识别方法的综合题。

只替换数字、变量名或输入顺序，不能证明发生了迁移。每道变式旁边写两行：

```text
保留的底层动作：
改变的前提或表面形式：
```

如果前提变化导致原方法不再成立，要把“需要重新判断”记录为结果，不能强行套用旧模板。

### 6. 每次练习都落一行台账

```text
日期 | 编号 | 来源 | 主题 | 是否独立 | 结果 | 错因/卡点 | 证据位置 | 下一步
```

做对的题也记录“对”，不要求重复抄写完整过程。没有交卷、只看过讲解或只凭记忆判断的，分别标为“未交卷”“仅阅读”“自述”，不要混入独立完成数量。

### 7. 间隔后重做，再更新状态

至少隔一段时间关闭答案、旧草稿和提示，只保留题面与必要条件。重做时检查：

1. 是否还能选对方法；
2. 是否写出了关键前提；
3. 是否能完成中间步骤；
4. 是否能指出最容易错的地方；
5. 换一个表面形式后，原规则是否仍适用。

重做失败要记录失败位置。不要直接复制旧解答，否则台账会显示“做过”，却无法说明是否能独立复现。

### 8. 每周对账，防止练习记录漂移

每周检查三组数量是否能相互解释：

- 练习台账中的实际尝试数；
- 错题与缺口卡中的题目数；
- 阶段测评回填的题目数。

对不上时，先找漏记、重复编号、跨文件撞号和只有口头记录的题目。不要用“约做过多少题”填补差额。

## 交付物

一轮合格的复习至少留下：

1. 一份素材索引，区分来源和用途；
2. 一份练习台账，记录实际尝试和证据位置；
3. 一组缺口卡，每张卡只有一个主要错误机制；
4. 一次小型混合测评，以及按缺口分类的回填；
5. 一轮间隔重做记录；
6. 一份下一周停止线，说明先处理哪些缺口，暂时不新增哪些题。

## 验收

逐项回答下面的问题：

- 能否把“收集过”和“实际练过”分开统计？
- 任意一条错误记录，是否都能指向一个具体修正动作？
- 任意一个“已完成”状态，是否有题目、日期和证据位置？
- 是否至少有一道题在间隔后独立重做，而不是照抄旧答案？
- 是否明确区分了答案正确、过程合法、条件齐全和能够迁移？
- 一次测评的结论是否限制在本次题目、时间和评分标准内？

如果其中一项答不上来，把状态降为“记录不完整”或“待重建”，不要用“基本掌握”填空。

## 常见失败与修正

| 失败 | 根因 | 修正 |
| --- | --- | --- |
| 题库不断变大 | 用收集替代练习 | 设停止线，先完成当前缺口卡和间隔重做 |
| 错题越积越多 | 只存题面，不存错误机制 | 每题只提炼一个首要错因和一个修正动作 |
| 分数上升就宣称掌握 | 样本、难度或评分标准发生变化 | 保留测评边界，另做变式和间隔重做 |
| 做对却不敢确认 | 缺少复核标准 | 对照条件、关键步骤和反例，不靠感觉重判 |
| 题号越记越乱 | 多套材料从同一个数字开始编号 | 为集合加前缀，引用时带完整编号 |
| 写了很多“注意事项” | 没有可执行动作 | 把每条提醒改写成顺序、字段、输入或验收条件 |

## 边界

- 这套方法能提高记录和复习决策的清晰度，不能替代教师批改、教材证明或独立的学科正确性检查。
- 来源没有作答、运行或测评记录时，要写“来源未提供完整记录；本轮仅整理，未执行验证”。
- 外部题库、教材照片、课程平台内容和原始截图不因进入个人资料库就自动获得公开许可。公开版只保留自行改写的方法、必要的短例和原始链接或来源说明。
- 个人分数、学校或课程信息、账号、文件绝对路径、对话记录和手写照片不属于通用方法的必要内容，应留在私有记录中。
- “能独立重做一道题”只能说明这一道题达到某个状态，不能推出整章或整门课已经掌握。
