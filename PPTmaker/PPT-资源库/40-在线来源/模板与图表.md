# 模板、图表与地图来源

| 来源 | 适合场景 | 使用原则 |
| --- | --- | --- |
| [Microsoft Create](https://create.microsoft.com/) | PowerPoint 原生模板、时间线、报告类页面 | 优先选结构，不照搬颜色和装饰；按具体页面当前许可使用 |
| [SlidesCarnival](https://www.slidescarnival.com/) | 学术和课堂汇报模板参考 | 下载前逐份核对署名与使用条款；项目内保留原始下载包 |
| [Datawrapper](https://www.datawrapper.de/) | 数据图、地图和可嵌入图表 | 先定义指标与图表目的，图表只是证据容器 |
| [Natural Earth](https://www.naturalearthdata.com/) | 地图底图、区域和路线示意 | 数据为 Public Domain；地图上呈现的统计数据仍需单独引用 |
| [diagrams.net](https://www.diagrams.net/) | 流程图、系统图、研究框架 | 用于先画清关系，再导出 SVG 或 PNG 放入课件 |

禁止把一张图表截图后去掉来源。数字、单位、时间范围和数据口径必须跟随图表。
