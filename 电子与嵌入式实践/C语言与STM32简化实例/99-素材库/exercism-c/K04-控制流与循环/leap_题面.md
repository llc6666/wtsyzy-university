# 题面：闰年

> 来源：exercism/c 仓库 `exercises/practice/leap`（MIT 许可）。中文译写，英文原件未保留。

任务：判断给定的年份是不是闰年。

## 规则（题面未展开，按通行规则）

- 能被 4 整除的是闰年
- 但能被 100 整除且不能被 400 整除的**不是**闰年
- 能被 400 整除的是闰年

## 官方签名（来自参考解）

```c
bool leap_year(int year);
```

## 这一题的考点

题面只有一句话，规则要自己列全。常见漏法是只判「能被 4 整除」，忘了 100 与 400 这两层例外——正好对应 K04 的「分支要覆盖全部情况」。
