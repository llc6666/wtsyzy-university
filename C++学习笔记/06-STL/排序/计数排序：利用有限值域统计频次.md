# 计数排序：利用有限值域统计频次

## 什么时候用

元素是非负整数，且最大值与最小值之间的范围很小。例如成绩在 `0..100`、年龄在 `0..150`。它不通过比较元素大小排序，而是直接记录每个值出现几次。

## 机制

`count[value]` 存“值为 `value` 的元素数量”。先遍历输入把计数加一，再按数值从小到大输出每个值对应次数，就得到有序序列。值域宽度 `range` 决定计数数组大小，不是元素数 `n`。

## 最小可运行示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

void counting_sort(std::vector<int>& a) {
    int max_value = *std::max_element(a.begin(), a.end());
    std::vector<int> count(max_value + 1, 0);

    for (int x : a) ++count[x];

    int pos = 0;
    for (int value = 0; value <= max_value; ++value) {
        while (count[value]-- > 0) a[pos++] = value;
    }
}

int main() {
    std::vector<int> a = {2, 1, 3, 2, 0};
    counting_sort(a);
    for (int x : a) std::cout << x << ' ';
}
```

预期输出：

```text
0 1 2 2 3
```

## 如何验证

把输入改为 `{4, 4, 1, 0}`，输出应为 `0 1 4 4`。同时观察 `count` 的长度为 `5`，因为最大值是 `4`，而不是因为输入有 4 个元素。

## 复杂度与边界

- 时间：`O(n + range)`；空间：`O(range)`。
- 上例仅支持非空、非负整数。出现负数时需用 `x - min_value` 做偏移。
- 若数据是 `{1, 1000000000}`，只为两个数申请十亿大小的数组不可接受，应改用比较排序或哈希统计后排序键。
- 上例重写数组，不保留相等元素的原始附加信息；要稳定地排序对象，需要累积计数并从后向前写入输出数组。
