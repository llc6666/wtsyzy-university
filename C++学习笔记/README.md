# C++ 学习笔记

这里收录 61 篇原创学习笔记和一个可独立编译的代码示例。内容面向 C++ 入门到 STL、基础数据结构和基础算法。

## 阅读顺序

1. `01-基础语法`：控制流、数组、字符串、类型与运算符。
2. `02-函数与对象`、`03-指针与链表`：函数返回、对象生命周期、空指针、链表和队列。
3. `04-输入输出`、`05-数据结构`：格式化、编码、队列与一个 DSP 场景。
4. `06-STL`：容器、头文件和排序。
5. `07-基础算法`：两道 Codeforces 题的建模过程。
6. `学习方法`：如何写可复用笔记，以及如何确认编译器与语言标准。

## 使用边界

- 这些是个人学习笔记，适合作为理解和复习材料；标准细节以 [cppreference](https://en.cppreference.com/w/cpp) 和编译器官方文档为准。
