# 大学学习与决策方法

这是一个面向本科生的公开知识库，收录可迁移的学习、课程规划、项目选择与职业判断方法。

它不提供任何学校的具体制度、课程名单、选课技巧、个人经验样本或实时信息。具体学校的培养方案、选课通知、竞赛规则、价格和岗位要求，应回到官方来源核验。

## 使用边界

- 内容是决策和学习框架，不构成学校政策、职业承诺、购买建议或医疗、法律、财务建议。
- 当内容与当前官方文件冲突时，以官方文件为准。
- 任何涉及个人信息、账号、成绩、学校内部流程、未公开材料和第三方原文，均不应提交到本仓库。

公开编译的范围与脱敏规则见 [公开边界与脱敏说明](公开边界与脱敏说明.md)。
