# 嵌套循环的停止：break 只跳出内层循环

## 问题

当 `for` 位于 `while` 内部时，内层 `for` 中的 `break` 只结束 `for`，不会结束外层 `while`。

因此，如果要处理恰好 `d` 个元素，外层循环也必须使用 `i < d` 作为条件，或额外设置停止标志。

## 原代码的问题

```cpp
while (i <= d) {
    for (...) {
        ...
        i++;
        if (i == d) {
            break;
        }
    }
    n++;
}
```

当 `i == d` 时，`break` 只跳出 `for`。随后执行 `n++`，再回到 `while (i <= d)`。因为 `i` 仍等于 `d`，条件仍然成立，外层循环会多执行一次。

## 推荐写法

计数变量从 `0` 开始，表示已经输出的元素个数：

```cpp
#include <iostream>
using namespace std;

int main() {
    int d;
    cin >> d;

    int m = 0;
    int i = 0;
    int n = 1;

    while (i < d) {
        for (int j = 0; j < n && i < d; ++j) {
            m += n;
            cout << n << ' ';
            ++i;
        }
        ++n;
    }

    cout << m;
    return 0;
}
```

输入 `4` 时：

```text
1 2 2 5
```

其中 `1 2 2` 是循环输出的三个数，`5` 是最后输出的 `m`。如果希望换行区分结果，可以写：

```cpp
cout << '\n' << m;
```

## 为什么这个版本能正确停止

内层条件：

```cpp
j < n && i < d
```

当已经输出 `d` 个元素时，内层循环不再继续。

外层条件：

```cpp
while (i < d)
```

当 `i == d` 时，外层循环也不会再次进入。

## 如果只修改原代码

最小修改是把：

```cpp
while (i <= d)
```

改成：

```cpp
while (i < d)
```

原来的内层 `break` 仍然可以保留：

```cpp
while (i < d) {
    for (int j = 0; j < n; ++j) {
        m = m + n;
        cout << n << ' ';
        ++i;
        if (i == d) {
            break;
        }
    }
    ++n;
}
```

不过推荐把 `i < d` 也写进内层循环条件，停止条件更直接。

## 如何验证

把外层循环设为 3 次、内层循环设为 5 次，并在内层遇到 `j == 2` 时执行 `break`。输出外层下标：应看到外层仍依次执行 0、1、2；只有每一轮内层在 2 后停止。若目标是整个双层循环停止，必须用标志位、函数 `return` 或其他明确的外层控制。

## 边界

`break` 只离开它所在的最内层循环或 `switch`。不要把它当作“结束所有循环”的语法糖；当退出路径超过一层时，显式表达控制流。

## 使用规则

1. `break` 只结束它所在的最内层循环。
2. 嵌套循环要彻底停止，必须让外层条件也变为假，或使用标志变量、`return`。
3. 计数“已经处理了多少个元素”时，推荐从 `0` 开始。
4. 处理恰好 `d` 个元素时，条件通常写 `i < d`，而不是 `i <= d`。
