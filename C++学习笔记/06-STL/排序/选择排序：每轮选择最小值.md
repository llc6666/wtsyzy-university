# 选择排序：每轮选择最小值

## 什么时候用

用于理解“已排序区间和未排序区间”的划分，或元素交换极其昂贵、规模很小时。日常 C++ 排序用 `std::sort`。

## 机制

第 `i` 轮在 `i..n-1` 中记录最小元素的位置 `min_pos`，然后与 `a[i]` 交换。第 `i` 轮结束后，`a[i]` 已经是剩余元素中的最小值，因此左侧区间逐步固定。

## 最小可运行示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

void selection_sort(std::vector<int>& a) {
    for (int i = 0; i + 1 < static_cast<int>(a.size()); ++i) {
        int min_pos = i;
        for (int j = i + 1; j < static_cast<int>(a.size()); ++j) {
            if (a[j] < a[min_pos]) min_pos = j;
        }
        if (min_pos != i) std::swap(a[i], a[min_pos]);
    }
}

int main() {
    std::vector<int> a = {64, 25, 12, 22, 11};
    selection_sort(a);
    for (int x : a) std::cout << x << ' ';
}
```

预期输出：

```text
11 12 22 25 64
```

## 如何验证

在内层循环后临时输出 `i` 和 `min_pos`。每一轮都应看到未排序区间中的最小值被选中。把输入改为 `{3, 1, 3, 2}`，数值顺序正确，但相等元素原有顺序可能因远距离交换而改变。

## 复杂度与边界

- 任意输入都要扫描未排序区间，比较次数约为 `n(n-1)/2`，时间 `O(n^2)`。
- 至多 `n-1` 次交换，额外空间 `O(1)`。
- 通常不稳定：一次交换可能让后面的相等元素跨到前面。
- 没有“接近有序就很快”的优势，数据规模大时不要手写使用。
