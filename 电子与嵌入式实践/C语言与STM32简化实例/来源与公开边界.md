# 来源与公开边界

## 本目录发布的内容

- 本人编写的 C 语言和嵌入式最小示例
- 本人整理的知识点说明、错误分析、练习任务和验证记录
- 为了说明来源而保留的项目名、练习名和官方文档入口

## 本批特批发布的内容

- `00-索引与说明/`：练习索引、易错清单、来源与许可登记、搬运说明
- `99-素材库/`：已整理的题面、合并后的完整题面、参考解、接口文件、课程章节与示例代码

上述内容按本批次特批进入公开库，仍保留原来源与许可边界，不代表第三方许可证发生变化。

## 仍不随公开库发布的内容

- 原始下载压缩包、原始解压目录、完整工程和编译产物
- 与本练习库无关的课程字幕、课件原件和本地资料原件
- 用户电脑绝对路径、用户名、私有索引和本地构建缓存

公开版的 `读-示例分析.md` 保留阅读结论与错误定位，外来代码片段已省略；`C知识点/`、`嵌入式专题/` 与根目录速览中的 C 文件为本库自写示例。`99-素材库` 包含第三方参考代码，属于本批特批的参考资料区，不能被理解为原课程或原仓库的重新许可。

## 参考来源

- [Exercism C](https://github.com/exercism/c)：用于练习主题和接口风格的参考。
- [GCC 官方文档：Volatile](https://gcc.gnu.org/onlinedocs/gcc/Volatiles.html)：用于核对 `volatile` 的编译器语义边界。
- STM32 标准外设库、参考手册和课程资料：用于场景名称、寄存器模型和工程结构的交叉参考；具体芯片行为仍以对应芯片手册和实测为准。

外部来源只用于学习和核对，公开库不替代原始许可证，也不声称拥有第三方资料的版权。
