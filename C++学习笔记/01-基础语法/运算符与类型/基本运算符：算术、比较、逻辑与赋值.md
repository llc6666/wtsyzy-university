# 基本运算符：算术、比较、逻辑与赋值

## 一句话结论

运算符把一个或多个值组合成表达式。初学阶段先掌握：算术、赋值、比较、逻辑、自增自减和条件运算符；遇到多个运算符时，复杂表达式优先加括号，不依赖记忆优先级。运算符优先级决定表达式如何分组，但不等于所有子表达式的实际求值顺序。

## 算术运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b` |
| `%` | 取余 | `a % b` |

```cpp
int a = 7;
int b = 2;

std::cout << a + b; // 9
std::cout << a - b; // 5
std::cout << a * b; // 14
std::cout << a / b; // 3，整数除法
std::cout << a % b; // 1，余数
```

两个 `int` 相除时，小数部分被截去：

```cpp
int result = 7 / 2; // 3
```

需要小数时，让至少一个操作数是浮点数：

```cpp
double result = 7.0 / 2; // 3.5
```

## 赋值运算符

```cpp
int x = 10;
x = 20;
```

常见复合赋值：

```cpp
x += 3; // x = x + 3
x -= 3; // x = x - 3
x *= 3; // x = x * 3
x /= 3; // x = x / 3
x %= 3; // x = x % 3
```

`=` 是赋值，不是比较。比较相等使用 `==`。复合赋值也是一次修改操作，例如 `x += 3`。

## 比较运算符

| 运算符 | 含义 |
| --- | --- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于或等于 |
| `<=` | 小于或等于 |

比较表达式的结果是 `bool`：

```cpp
int a = 10;
int b = 20;

bool result = a < b; // true
```

## 逻辑运算符

```cpp
&& // 逻辑与：两边都为真
|| // 逻辑或：至少一边为真
!  // 逻辑非：真假取反
```

```cpp
int age = 20;

if (age >= 18 && age < 60) {
    std::cout << "符合范围\n";
}
```

`&&` 和 `||` 具有短路行为：`&&` 左边为假时不计算右边，`||` 左边为真时不计算右边。利用这一点可以安全地访问可能为空的指针：

```cpp
if (p != nullptr && p->data == target) {
}
```

## 自增与自减

```cpp
++i; // 先加 1，再产生新值
--i; // 先减 1，再产生新值
i++; // 先产生旧值，再加 1
i--; // 先产生旧值，再减 1
```

单独写成一行时，`i++` 与 `++i` 的最终结果相同。需要使用表达式值时，才需要区分前置和后置形式。

## 次方运算

C++ 没有内置的次方运算符。下面的 `^` 不是次方，而是按位异或：

```cpp
int x = 2 ^ 3; // 按位异或，结果为 1，不是 8
```

计算一般次方可以使用 `<cmath>` 中的 `std::pow`：

```cpp
#include <cmath>

double result = std::pow(2.0, 3.0); // 8.0
```

`std::pow(base, exponent)` 表示 `base` 的 `exponent` 次方。它通常返回浮点类型；如果结果本应是整数，浮点计算可能带来精度问题。小整数次方直接相乘更简单：

```cpp
long long result = 2LL * 2 * 2; // 8
```

需要对大整数做整数次方，特别是取模时，使用快速幂：

```cpp
long long power_mod(long long base, long long exponent, long long mod) {
    long long result = 1 % mod;
    base %= mod;

    while (exponent > 0) {
        if (exponent & 1) {
            result = result * base % mod;
        }
        base = base * base % mod;
        exponent >>= 1;
    }

    return result;
}
```

例如：

```cpp
power_mod(2, 10, 1000); // 24，因为 2^10 = 1024，1024 % 1000 = 24
```
## 条件运算符

三目运算符格式：

```cpp
条件 ? 条件为真时的值 : 条件为假时的值
```

```cpp
int a = 10;
int b = 20;
int maxValue = a > b ? a : b;
```

它适合简单的值选择。需要执行多条语句时，使用 `if ... else` 更清楚。

## 位运算符

```cpp
&  // 按位与
|  // 按位或
^  // 按位异或
~  // 按位取反
<< // 左移
>> // 右移
```

它们处理整数的二进制位，不要与 `&&`、`||` 混淆：

```cpp
int result = 10 & 6; // 2，逐位计算
bool ok = 10 && 6;   // true，判断两个非零值
```

位运算详见：位运算符：按位与和按位或。

## 地址、解引用和成员访问

这些符号也常见，但作用取决于上下文：

```cpp
int value = 10;
int* p = &value; // 一元 &：取地址
int x = *p;      // 一元 *：解引用，取出 p 指向的值
```

结构体指针访问成员：

```cpp
Node* p = head;
p->data; // 等价于 (*p).data
```

## 运算符优先级的最低实用规则

```cpp
int result = a + b * c;
```

乘法先于加法，等价于：

```cpp
int result = a + (b * c);
```

但不要把表达式写得过于依赖优先级：

```cpp
if ((flags & mask) != 0) {
}
```

括号明确表达“先取掩码，再比较结果”。复杂条件也建议加括号：

```cpp
if ((a > 0 && b > 0) || c == 1) {
}
```

## 常见错误

```cpp
if (x = 0) { }  // 赋值
if (x == 0) { } // 比较
```

```cpp
int x = 7 / 2; // 3，不是 3.5
```

```cpp
// arr[i++] = i; // 不推荐：同时读写并改变 i，意图难以判断
```

应拆开：

```cpp
arr[i] = i;
++i;
```

## 使用规则

1. 算术运算先确认操作数类型，尤其注意整数除法和乘法溢出。
2. `=` 是赋值，`==` 是比较。
3. 普通条件使用 `&&`、`||`，位操作使用 `&`、`|`。
4. 可能为空的指针，先判断 `p != nullptr`，再访问 `p->member`。
5. 复杂表达式加括号；优先级表只用于核对，不用于炫技。
6. 自增表达式不必塞进复杂表达式，拆开更安全。
