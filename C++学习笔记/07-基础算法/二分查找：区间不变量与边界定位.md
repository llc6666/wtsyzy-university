# 二分查找：区间不变量与边界定位

## 适用场景

二分查找用于两类问题：

1. 在按同一规则有序的序列中定位一个值或边界。
2. 在答案范围中寻找一个单调判定的分界点，例如“第一个可行值”。

它的前提不是“数组很大”，而是每次比较后都能证明丢弃的一半不可能包含答案。对升序数组，`a[i] >= target` 会形成“假、假、真、真”的分界；这正是定位第一个不小于目标值的位置所需的结构。

## 你需要准备什么

- 一个可随机访问的升序 `std::vector<int>`。
- 明确的目标：找任意匹配项，还是找第一个满足条件的位置。
- 一套不混用的区间约定：本页精确查找用闭区间 `[l, r]`，边界定位用半开区间 `[l, r)`。

无序序列、真假值反复变化的 `check(x)`，都不适用本页模板。先排序是否会破坏原下标或原顺序含义，也必须先判断。

## 按什么顺序做

### 1. 先写出区间承诺

精确查找使用闭区间时，承诺是：

```text
目标若存在，一定在 [l, r] 中。
```

初始值为 `l = 0`、`r = n - 1`。当 `l > r`，候选区间为空，返回“未找到”。

定位第一个 `>= target` 的位置时，使用半开区间：

```text
[0, l) 全部 < target
[r, n) 全部 >= target
答案在 [l, r) 中；r 可以等于 n
```

初始值为 `l = 0`、`r = n`。因此空数组也能直接处理，循环不会访问元素。

### 2. 每一轮只保留仍可能正确的一侧

对于精确查找：

```cpp
if (a[mid] < target) l = mid + 1;
else if (a[mid] > target) r = mid - 1;
else return mid;
```

对于“第一个 `>= target`”：

```cpp
if (a[mid] >= target) r = mid;
else l = mid + 1;
```

满足条件的 `mid` 不能从候选中丢掉，因为它可能就是最靠左的位置。这也是边界模板不能照搬精确查找 `r = mid - 1` 的原因。

### 3. 检查区间是否真的缩小

`mid` 用下面的写法计算：

```cpp
int mid = l + (r - l) / 2;
```

它避免 `l + r` 直接相加的溢出。在半开区间的“第一个真”模板中，`l < r` 时必有 `mid < r`：`r = mid` 或 `l = mid + 1` 都会缩小区间。

若目标是“最后一个满足条件的位置”，通常需要向右取中点：

```cpp
int mid = l + (r - l + 1) / 2;
```

否则在 `l + 1 == r` 且执行 `l = mid` 时，区间可能不再缩小。

## 最后留下什么产物

本页配套示例：[二分查找边界定位.cpp](../代码示例/二分查找边界定位.cpp)。它提供三个函数：

- `find_value`：返回一个匹配下标，找不到返回 `-1`。
- `first_ge`：返回第一个 `>= target` 的下标；返回 `a.size()` 表示不存在。
- `std::lower_bound` 调用：验证标准库的边界语义。

示例输入序列固定为：

```text
[0, 1, 1, 1, 8, 9, 9]
```

预期输出：

```text
find(8) = 4
find(2) = -1
first_ge(1) = 1
first_ge(7) = 4
first_ge(10) = 7
lower_bound(8) = 4
```

1. 查找不存在的 `2`，精确查找必须返回 `-1`。
2. 查找重复元素 `1` 的下界，必须返回第一个 `1` 的下标 `1`。

## 常见失败与修正

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 循环卡住 | `l = mid` 搭配向下取整中点，区间没有缩小 | 用向上取整中点，或改用半开区间模板 |
| 重复值返回错误位置 | 把边界定位写成精确查找 | 找第一个满足条件时保留 `mid`，写 `r = mid` |
| `lower_bound` 结果异常 | 序列未按同一比较规则有序 | 先保证排序规则与查找比较器一致 |
| 解引用崩溃 | `lower_bound` 返回了 `end()` | 解引用前检查 `it != a.end()` |
| 找不到时下标越界 | 忘记尾后位置是合法返回值 | 将 `a.size()` 当作“无满足元素”的独立状态处理 |

## 什么时候不适用

- 需要保留原始输入顺序，且排序会改变问题含义。
- `check(x)` 存在“真、假、真”这类反复变化，无法形成单调分界。
- 数据结构不支持高效随机访问时，手写下标二分并不直接适用。标准库 `lower_bound` 可用于前向迭代器，但迭代器移动可能是线性的；关联容器优先使用自己的成员函数。

## 来源与复核要求

- [`std::lower_bound`](https://en.cppreference.com/cpp/algorithm/lower_bound)：范围必须按比较规则形成分区；返回第一个不小于目标的元素，或尾迭代器。
- [`std::binary_search`](https://en.cppreference.com/cpp/algorithm/binary_search)：只返回是否存在等价元素；需要位置时使用 `lower_bound`。
- 标准库细节、编译器支持和比较器要求可能随语言标准演进，使用前以当前文档为准。
