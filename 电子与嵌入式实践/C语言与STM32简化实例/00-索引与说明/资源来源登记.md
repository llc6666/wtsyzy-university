登记原则：来源 URL、许可、本地位置、在本库的用途、能不能外传。许可一律以仓库内实际文件为准，不凭 GitHub 页面的惯例推测。

公开边界：2026-10-01，用户明确特批本批题面、参考解和参考素材进入公开库；该特批不改变第三方许可证，也不等于原作者授予了新的再分发权。原始 ZIP、原始解压目录和完整工程仍不公开。

> 关于路径：本页与各知识点笔记里写的「本地」「来源」路径指向**原始解压目录**，用于溯源。这些目录属于原材料、不随库搬运，搬走之后这些路径会失效——做题要用的副本都在 [99-素材库](../99-素材库/README.md) 里。
>
> 另外：CrashCourse 部分教程原文里有指向作者本地桌面的图片链接（形如 `原作者本地目录/...\xx.png`），图片未随仓库分发，属原文本身的死链。相关文件顶部已加说明，理解以文字与字符图为准。

## 使用规则

1. 引用外来资料时写清「来源仓库 + 相对路径」，不把原文整篇复制进本库笔记；分析、归纳、改写由本人撰写。
2. 本批 #1、#2 的已整理素材按用户特批进入公开库；#4、#5、#6 仍不进公开库。
3. 练习题的参考解（`.meta/example.c`、Exercises 的 `.c`）只在自己写完并复盘后再看，用来对照思路，不照抄。
4. 新加入资料时补一行：来源 URL、下载日期、许可、本地路径、用途。
