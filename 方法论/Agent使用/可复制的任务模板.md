# 可复制的任务模板

## 何时用

不想每次从零组织需求，或多人需要向 Agent 提交相同类型任务时使用。模板是最低信息标准，不代替事实核验和人工审批。

## 输入

- 一项明确任务。
- 实际的路径、来源、交付物和验收条件。

## 步骤

### 1. 选择任务类型

| 类型 | 使用模板 | 必填差异 |
| --- | --- | --- |
| 知识库整理 | A | 来源、脱敏、链接检查 |
| 代码修改 | B | 复现、测试、兼容性、回退 |
| 调研报告 | C | 问题、来源等级、时效、反例 |
| 文件发布 | D | 发布范围、许可、外部确认 |

### 2. 填模板中的方括号

未填字段保留方括号，Agent 应把它列为待确认项。不要用“你看着办”“尽量完善”代替关键输入。

### 模板 A：知识库整理

```text
任务：将 [来源范围] 中与 [主题] 有关的内容，编译为 [目标目录] 的 [页面类型]。
可读取：[精确目录/文件]；可编辑：[精确目录]；禁止读取或发布：[范围]。
要求：保留来源链接/日期；事实、推论、行动分开；写适用条件和反例；更新入口页。
交付物：[文件清单]。
验收：本地链接检查、来源抽查、敏感信息扫描、人工阅读一条操作步骤。
停止条件：来源无原件、出现内部资料、目标文件已有未确认改动时先报告。
```

### 模板 B：代码修改

```text
任务：在 [仓库/模块] 修复 [可复现问题]，不改变 [明确不可变行为]。
现象：[输入、命令、预期、实际、报错]。
可读取/编辑范围：[路径]；禁止操作：[删除、依赖升级、外部部署等]。
先做：阅读规则、检查工作区状态、复现问题、说明最小修复计划。
验收：运行 [测试命令]；覆盖 [正常/边界] 样例；执行 diff 检查。
交付物：补丁、测试结果、影响说明、回退方式。
停止条件：无法复现、会覆盖未提交改动、需要修改公共接口时先确认。
```

### 模板 C：调研与判断

```text
问题：[具体问题]；截止日期：[日期]；使用场景：[决策/学习/报告]。
优先来源：[官方文件、原始数据、论文、访谈]；禁止使用：[无来源转述等]。
输出：事实表、不同解释、当前判断、适用边界、反例、待验证问题。
每条关键事实附来源与获取日期；把推论标为推论。
验收：随机抽查 [N] 条事实可回到来源；结论不超出样本和时效范围。
停止条件：关键来源冲突或不可访问时，报告不确定性，不强行下结论。
```

### 模板 D：公开发布

```text
任务：将 [候选文件] 发布到 [平台/仓库]。
发布范围：[文件列表]；不发布：[隐私、内部材料、第三方原文、凭据]。
发布前：展示差异、来源与许可、文本扫描结果、图片/附件人工检查结果。
必须人工确认：远程推送、公开可见性、收件人、金额或删除动作。
验收：未登录环境可访问；链接可用；公开内容无敏感信息；发布记录已保存。
```

### 3. 运行前做 60 秒口头检查

依次问：目标能验收吗？资料有来源吗？路径和权限明确吗？失败会造成什么？谁批准外部动作？答不出来时，模板仍未完成。

## 交付物

- 一份已填模板。
- 一张 Agent 开始前复述的范围与计划。
- 一份结束时的验证与交接记录。

## 验收

- 方括号均已填写或被显式标为待确认。
- 模板内存在可读取范围、可编辑范围、验收和停止条件。
- 高风险动作列为人工确认，而非默认执行。

## 常见失败与修正

- 模板越写越长：保留决定范围、证据、权限和验收的字段，删除纯风格要求。
- 复制旧路径和日期：每次运行先替换范围、版本和时效信息。
- 用模板掩盖不懂业务：让 Agent 先提出澄清问题，并把答案写回任务契约。
- 模板通过一次就不再测试：用成功、失败、边界三类历史任务定期回放。
