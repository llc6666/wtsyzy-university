# 四年阶段规划框架

## 结论

长期规划不应把所有目标同时设为最高优先级。更合理的方式是把学习阶段拆开：每段只解决一个主问题，留下少量可检查产出，再根据结果调整下一段。

## 一个通用的四阶段模型

| 阶段 | 主问题 | 代表性产出 |
| --- | --- | --- |
| 建立基础 | 规则、课程和基本能力是什么？ | 课程地图、基础训练记录 |
| 形成假设 | 哪些方向值得继续投入？ | 小项目、能力差距表 |
| 真实验证 | 能否在真实任务中稳定交付？ | 项目成果、外部反馈 |
| 收敛与迁移 | 如何整理成果并决定下一步？ | 作品集、复盘、决策记录 |

这是一种思考顺序，不是所有人的固定年表。转向、间隔、家庭变化和偶然机会都会改变节奏。

## 使用方法

1. 先确定当前阶段的唯一主问题。
2. 只保留一项主目标和两到三项次目标。
3. 为每个目标规定可检验的完成证据。
4. 每周只维护下一步行动，每个周期复盘判断是否仍然成立。
5. 对没有新证据价值的任务及时停止。

## 边界

产出数量不等于能力质量。规划能改善选择过程，却无法保证成绩、机会或结果。遇到重大现实变化时，优先修正约束，而非硬守旧计划。
