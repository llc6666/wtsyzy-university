# 选择排序

每轮在未排序区间找最小值，再和区间第一个元素交换。

```cpp
void selection_sort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int min_pos = i;

        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[min_pos]) {
                min_pos = j;
            }
        }

        if (min_pos != i) {
            std::swap(a[i], a[min_pos]);
        }
    }
}
```

比较次数固定为 `O(n^2)`，通常不稳定；优势是交换次数较少。
