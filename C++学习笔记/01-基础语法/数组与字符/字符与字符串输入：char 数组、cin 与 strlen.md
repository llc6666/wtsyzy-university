# 字符与字符串输入：char 数组、cin 与 strlen

## 一句话结论

`char` 是存单个字符的格子，字符数组（`char s[100]`）是一排字符格子。`cin >> s` 把一串字符按顺序塞进格子，`strlen(s)` 返回字符个数（需 `#include <cstring>`），用下标 `s[i]` 逐个访问，用 `==` 比较字符。

## 它解决什么问题

程序经常要处理"一串字符"：读入一行输入、判断括号是否配对、检查单词。字符数组是 C++ 里最基础的字符串形式，是处理字符序列的起点。

## 工作机制

```cpp
#include <iostream>
#include <cstring>   // strlen 所在
using namespace std;

int main() {
    char s[100];        // 一排字符格子，最多 99 个字符
    cin >> s;           // 输入 (()())，按顺序塞进格子
    int len = strlen(s); // len = 6
    for (int i = 0; i < len; i++) {
        if (s[i] == '(') { ... }   // 逐个访问 + 比较
    }
}
```

六个要点：

1. **char**：单个字符，字面量用单引号：`'('`、`'a'`。双引号 `"("` 是字符串，两回事。
2. **字符数组**：`char s[100]`，本质是数组，下标从 0 开始。
3. **cin >> s**：按顺序把字符塞进格子，遇空格或回车停止。
4. **strlen(s)**：返回有效字符个数，需要 `<cstring>`。
5. **下标访问**：`s[0]` 第一个，`s[i]` 第 i+1 个；遍历用 `for (int i = 0; i < len; i++)`。
6. **字符比较**：char 本质是整数（ASCII 码），`'('` 的值是 40，所以可以直接 `==` 比较。

## 最小示例

```cpp
char s[100];
cin >> s;                 // 输入 ab(c
int len = strlen(s);      // len = 4
cout << s[0];             // a
if (s[2] == '(') { ... }  // 真
```

## 常见错误与边界

1. **单引号双引号混用**：`s[0] == "("` 编译错误，字符比较必须单引号。
2. **忘写 `<cstring>`**：`strlen` 报错未声明。
3. **数组越界**：`char s[5]` 却输入 10 个字符，会溢出写坏相邻内存。数组要留足空间，且 `cin >> s` 不检查长度。
4. **cin >> s 遇空格停**：输入 `() ( )` 只读走第一段 `()`。需要读整行得用别的函数（后续学）。
5. **字符和数字不是一回事**：`'0'`（值 48）和 `0`（值 0）完全不同，`'0' + 1` 得到 `'1'` 而不是 1。
6. **strlen 不数 '\0'**：字符串结尾有个隐藏的结束符 `'\0'`，strlen 数的是它前面的字符数。

## 如何验证

输入 `hello world` 分别交给 `cin >> buffer` 与整行读取版本。前者长度应为 5，只保留 `hello`；整行读取才会保留空格。再输入长度等于数组容量的文本，程序必须预留结尾的 `\0`，否则 `strlen` 的结果不可依赖。

## 使用规则

- 字符字面量一律单引号。
- 用 strlen 前记得 `#include <cstring>`。
- 数组长度按"可能输入的最长情况"留余量。
- 逐个处理字符用 for + 下标。
- 需要整行输入时，不要用 `cin >>`，另行处理。
