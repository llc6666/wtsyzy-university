三个 `if` 平铺，没有 `else`——这是本知识点最重要的一条：**条件不互斥时不要用 `else if` 链**。

另外三点值得注意：

1. **用 `strlen(result) == 0` 判断「一个都没命中」**，而不是另设一个标志变量。前提是调用方给的数组一开始是空串（首字节为 `\0`）
2. 用 `snprintf` 而不是 `sprintf`：前者带长度限制，不会越界
3. `char drops_string[12]` 的长度是按 `int` 最大位数（含负号与 `\0`）估的

## 三、CrashCourse《07-选择语句》《08-循环》

来源：`99-素材库/hairrrrr-C-CrashCourse/K04-控制流与循环/`（本地未发现 LICENSE，本批按特批入库，许可状态不变）

读的时候抓三点：

- `if / else if / else` 的匹配规则（else 总是匹配最近的未匹配 if）
- `switch` 的贯穿（fall-through）行为，以及 `break` 漏写的后果
- `while` / `do-while` / `for` 的执行顺序差别，尤其是 `do-while` 至少执行一次

嵌入式里的对应关系：`switch` 常用于状态机，`for` 常用于定长缓冲区遍历，`while(1)` 是主循环。

## 读码小结

1. 看到多个 `if` 平铺，先问「这些条件会不会同时成立」
2. 看到多层例外，检查顺序是否把最特殊的条件放在前面
3. 看到 `strcat`，先确认目标数组已有 `\0` 且容量够
