# while(t--)：递减表达式作为循环条件

## 一句话结论

`while (t--)` 每轮先判断 `t` 当前是否为非零，再把 `t` 减 1；因此当初始 `t` 为正数时，循环体通常执行 `t` 次。

## 等价理解

```cpp
while (t--) {
    // 循环体
}
```

可以拆成：

```cpp
while (t != 0) {
    // 循环体
    --t;
}
```

这里的关键在于后置自减 `t--`：

1. 先使用 `t` 当前的值作为条件。
2. 再让 `t` 减 1。
3. 条件值非零时进入循环体，条件值为零时停止。

## 例子：t = 3

```cpp
#include <iostream>

int main() {
    int t = 3;

    while (t--) {
        std::cout << "执行一次，当前剩余值：" << t << '\n';
    }

    std::cout << "循环结束，t = " << t << '\n';
    return 0;
}
```

执行过程：

| 判断前的 `t` | 条件使用的值 | 自减后的 `t` | 是否执行循环体 |
| ---: | ---: | ---: | --- |
| 3 | 3，真 | 2 | 执行 |
| 2 | 2，真 | 1 | 执行 |
| 1 | 1，真 | 0 | 执行 |
| 0 | 0，假 | -1 | 停止 |

循环体执行 3 次。注意，最后一次判断中 `t--` 仍然会把 `0` 减为 `-1`，所以循环结束后 `t` 为 `-1`。

## 与 `while (t > 0)` 的区别

```cpp
int t = 3;

while (t > 0) {
    // 循环体
    --t;
}
```

这段代码循环体也执行 3 次，但结束后 `t == 0`。如果只想表达“执行 t 次”，并希望计数变量自然停在 0，这种写法更直观。

## 常见用途

### 处理 t 组测试数据

```cpp
#include <iostream>

int main() {
    int t;
    std::cin >> t;

    while (t--) {
        int x;
        std::cin >> x;
        std::cout << x * x << '\n';
    }

    return 0;
}
```

如果输入 `3 2 4 5`，程序处理 3 组数据：`2`、`4`、`5`。

### 重复执行固定次数

```cpp
int t = 5;
while (t--) {
    // 执行 5 次
}
```

## 与 `while (--t)` 的区别

```cpp
int t = 3;

while (--t) {
    // 执行 2 次
}
```

执行过程是：先减 1，再判断。因此：

- `while (t--)`：先判断旧值，再减 1。
- `while (--t)`：先减 1，再判断新值。

当 `t = 3` 时，前者执行 3 次，后者执行 2 次。

## 使用边界

1. `t` 初始为正数时，`while(t--)` 适合表示执行固定次数。
2. `t == 0` 时，循环体一次也不执行，但 `t` 会变成 `-1`。
3. `t < 0` 时，条件仍然为真，会继续执行；若不断减小，最终可能发生有符号整数溢出，产生未定义行为。
4. 循环体中不要再次修改 `t`，否则实际次数会改变。
5. 如果代码需要表达复杂条件，使用 `while (t > 0)` 更容易阅读和调试。

## 记忆方法

```cpp
while (t--)
```

读成：

> 用当前的 `t` 判断，判断后让 `t` 减 1。
