## binary-search

- 签名：`const int *binary_search(int value, const int *arr, size_t length)`
- 题面要点：只对有序数组有效；找不到返回 NULL

### 验收标准（用例表 + 五类边界）

| 输入 | 期望 |
| --- | --- |
| 在 `[4,8,12,16,23,28,32]` 中找 `23` | 指向 23 的指针（下标 4） |
| 找 `4` | 下标 0（最左端） |
| 找 `32` | 下标 6（最右端） |
| 找 `5` | NULL |
| 找 `3` | NULL（小于最小值） |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `length == 0` | 返回 NULL，不越界访问 |
| 最小 | 单元素数组 | 命中返回它，不命中返回 NULL |
| 最大 | 很长的数组 | 循环次数约 log₂n |
| 相等 | 数组中有重复元素 | 返回其中任意一个即可（但应说明返回的是哪一个） |
| 非法 | `arr == NULL` | 返回 NULL，不崩溃 |

- 不变量：命中的话，`*返回值 == value`；不命中返回 NULL；比较次数不超过 ⌈log₂(n+1)⌉

### 复盘三问

1. **为什么对**
2. **暴力做法为什么不行**：顺序查找 O(n)，二分 O(log n)；n 很大时差距明显，n 很小时二分未必更快（还有分支预测与缓存的因素）
3. **哪里最容易错**：区间写法中途改变；`(low + high) / 2` 溢出；`length - 1` 在 length 为 0 时下溢

## spiral-matrix

- 签名：`spiral_matrix_t *spiral_matrix_create(int size)`
- 题面要点：从左上角 1 开始，顺时针向内螺旋；`size` 为 3、4 的示例见题面

### 验收标准（用例表 + 五类边界）

| 输入 | 期望 |
| --- | --- |
| `size = 1` | `[[1]]` |
| `size = 3` | 见题面示例（1 2 3 / 8 9 4 / 7 6 5） |
| `size = 4` | 见题面示例 |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `size = 0` | 返回一个 size 为 0 的矩阵（参考解的行为），或不分配；需明确自己的约定 |
| 最小 | `size = 1` | 只有一个元素 1 |
| 最大 | `size = 10` | 全部 100 个数正确填入，最大值 100 在中心附近 |
| 相等 | 同一 size 调用两次 | 两次结果一致（说明没有依赖未初始化的状态） |
| 非法 | 负数 size | 不得越界写入；按 0 处理或返回空 |

- 不变量：填的数字是 1 到 size² 各出现一次；相邻数字在矩阵中相邻；结果由调用方释放

### 复盘三问

1. **为什么对**
2. **暴力做法为什么不行**：这一题没有更"暴力"的做法，关键是四条边界的收缩顺序
3. **哪里最容易错**：每一圈收缩时上下左右边界差一；`size` 为奇数时中心那个数
