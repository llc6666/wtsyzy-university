# 假期的产出导向规划

## 何时用

假期开始前一周使用。目的不是排满时间，而是在下一阶段开始前完成少量能复用、能检查的产物，并留出恢复余量。

## 输入

- 假期起止日期和不可用日期。
- 下一阶段最可能遇到的 3 个问题。
- 每周可稳定投入的小时数。

## 步骤

### 1. 只选三个产出

固定保留：一个基础补足、一个信息/计划整理、一个可展示或可运行成果。每项都填“最低版本、验收、时长上限、停止条件”。

| 产出 | 最低版本 | 验收 | 时长上限 | 停止条件 |
| --- | --- | --- | --- | --- |
| 基础补足 |  |  |  |  |
| 信息整理 |  |  |  |  |
| 作品/项目 |  |  |  |  |

### 2. 用三段安排，而非每日排满

- 前 20% 时间：建环境、找官方资料、完成最小样例。
- 中间 60% 时间：做独立练习或项目主体，每周一次验收。
- 后 20% 时间：整理成果、补缺口、安排开学后第一周。

每周只安排 60% 至 80% 的可用时间。剩余时间用于休息、家庭、临时事务和计划误差。

### 3. 设置周检

每周固定 20 分钟回答：最小版本是否完成？实际时长是否超上限？下周删掉什么？不能回答时，先缩范围，不增加新课程、新工具或新项目。

### 4. 结束时打包交付物

每项产出都要有文件、链接、题目记录或行动清单。最后写一页“开学第一周”：第一件事、所需材料、最晚日期、可能阻碍和备选动作。

## 交付物

- 一张三产出计划表。
- 至少一个最小可运行/可检查成果。
- 一页开学第一周行动表。

## 验收

- 计划中没有超过 3 个主产出。
- 每项都有最低版本、时长上限和验收方法。
- 休息与不可用时间已预留。
- 假期末能打开成果，或明确记录停止原因。

## 常见失败与修正

- 目标写成“学完一门课”：改为能独立完成的 3 至 5 个任务。
- 第一周只看资料：第 3 天前必须产生最小样例或错题记录。
- 计划落后后拼命补：删除低优先级项，保护主产出和恢复时间。
- 假期结束没有交接：写开学第一周行动表，防止成果归档后失联。
