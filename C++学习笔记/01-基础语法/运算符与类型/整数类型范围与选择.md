# 整数类型范围与选择

## 一句话结论

`long` 的大小不是所有平台都一样；`long long` 至少能表示 64 位范围，实际常见为 64 位。写程序时不要只背类型名，优先用 `<limits>` 查看当前编译器的真实范围；需要固定宽度时使用 `<cstdint>` 中的 `int32_t`、`int64_t` 等类型。

## 常见 Windows/Dev-C++ 环境

在常见的 32 位或 64 位 Windows MinGW 环境中，通常是：

| 类型          | 常见大小 |                                                  有符号常见范围 |                          无符号常见范围 |
| ----------- | ---: | -------------------------------------------------------: | -------------------------------: |
| `short`     | 2 字节 |                                       `-32,768 ~ 32,767` |                     `0 ~ 65,535` |
| `int`       | 4 字节 |                         `-2,147,483,648 ~ 2,147,483,647` |              `0 ~ 4,294,967,295` |
| `long`      | 4 字节 |                         `-2,147,483,648 ~ 2,147,483,647` |              `0 ~ 4,294,967,295` |
| `long long` | 8 字节 | `-9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807` | `0 ~ 18,446,744,073,709,551,615` |

## 换成 `10` 的幂来看

这里的“是 `10` 的多少次方”通常指数量级，不是说最大值恰好等于某个 `10^n`。

| 类型 | 最大值的近似写法 | 数量级 |
| --- | ---: | ---: |
| `short` | `3.2768 × 10^4` | `10^4` |
| `int` | `2.147483648 × 10^9` | `10^9` |
| `unsigned int` | `4.294967295 × 10^9` | `10^9` |
| `long long` | `9.223372036854775807 × 10^18` | `10^18` |
| `unsigned long long` | `1.8446744073709551615 × 10^19` | `10^19` |

因此算法题中常见的判断可以这样理解：

```text
int：大约能处理 10^9 规模的单个整数
long long：大约能处理 10^18 规模的单个整数
```

但“数据达到 `10^9`”不代表一定要用 `long long`。例如 `int` 的最大值约为 `2.147 × 10^9`，可以保存 `10^9`；如果还要做两个 `10^9` 量级数的乘法，结果可能达到 `10^18`，就应使用 `long long`，并让乘法从一开始就在 `long long` 类型中进行：

```cpp
long long result = 1LL * a * b;
```

不要只看最终变量类型：

```cpp
long long result = a * b; // a、b 都是 int 时，乘法可能先按 int 发生溢出
```
## Linux 64 位环境的差异

在常见 64 位 Linux 环境中，`long` 通常是 8 字节，而 Windows 常见数据模型中 `long` 仍是 4 字节。因此不能简单认为：

```text
long 一定比 int 大一倍
```

语言只保证整数类型按顺序至少不比前面的类型窄：

```text
sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)
```

标准规定这些类型具有最低宽度要求；具体大小由实现和平台决定。

## 这些范围怎么来的

对于常见的 N 位有符号整数，范围大致是：

```text
-2^(N-1) 到 2^(N-1)-1
```

无符号整数范围是：

```text
0 到 2^N-1
```

例如 32 位 `int`：

```text
-2^31 到 2^31-1
```

也就是：

```text
-2,147,483,648 到 2,147,483,647
```

## 用程序查看真实范围

```cpp
#include <iostream>
#include <limits>

int main() {
    std::cout << "int: "
              << std::numeric_limits<int>::min() << " ~ "
              << std::numeric_limits<int>::max() << '\n';

    std::cout << "long: "
              << std::numeric_limits<long>::min() << " ~ "
              << std::numeric_limits<long>::max() << '\n';

    std::cout << "long long: "
              << std::numeric_limits<long long>::min() << " ~ "
              << std::numeric_limits<long long>::max() << '\n';

    std::cout << "sizeof(long) = " << sizeof(long)
              << " bytes\n";
}
```

`sizeof` 的单位是字节；1 字节在 C++ 中不必然等于 8 位，但现代普通 PC 上通常是 8 位。

## 有符号与无符号

```cpp
int a = -1;
unsigned int b = 1;
```

`unsigned` 去掉负数范围，把更多编码空间给了正数。但无符号运算容易产生绕回：

```cpp
unsigned int x = 0;
--x; // 得到该无符号类型的最大值，不会得到 -1
```

因此不要为了“范围大一点”就随意使用 `unsigned`。只有变量的语义确实不允许负数时才考虑它。

## 固定宽度整数

如果程序需要明确的 32 位或 64 位整数：

```cpp
#include <cstdint>

std::int32_t a = 100;
std::int64_t b = 10000000000LL;
std::uint64_t c = 0;
```

`int64_t` 的含义比 `long` 更明确：需要一个恰好 64 位的有符号整数。固定宽度类型在实现提供相应类型时可用。

## 常用整数与浮点类型范围

C++ 标准只规定类型的最小能力，具体大小还与平台、编译器和数据模型有关。下面先列常见 Windows 64 位 MinGW/Dev-C++ 环境，再看标准边界。

| 类型 | 常见大小 | 常见范围 | 大致数量级 | 主要用途 |
| --- | ---: | --- | --- | --- |
| `bool` | 1 字节 | `false`、`true` | `0` 或 `1` | 真假状态 |
| `char` | 1 字节 | `-128 ~ 127` 或 `0 ~ 255` | `10^2` | 字符和小整数，是否有符号取决于实现 |
| `short` | 2 字节 | `-2^15 ~ 2^15-1` | 约 `10^4` | 较小整数 |
| `int` | 4 字节 | `-2^31 ~ 2^31-1` | 约 `±2.1 × 10^9` | 一般整数、下标、计数 |
| `unsigned int` | 4 字节 | `0 ~ 2^32-1` | 约 `4.3 × 10^9` | 确定不需要负数时 |
| `long` | Windows 常见 4 字节 | `-2^31 ~ 2^31-1` | 约 `±2.1 × 10^9` | 平台相关，不能仅凭名字认为比 `int` 大 |
| `long long` | 8 字节 | `-2^63 ~ 2^63-1` | 约 `±9.22 × 10^18` | 大整数、总和、乘积 |
| `float` | 4 字节 | 约 `±3.4 × 10^38` | 约 `10^38` | 对精度要求不高的浮点数 |
| `double` | 8 字节 | 约 `±1.7 × 10^308` | 约 `10^308` | 常用浮点计算 |
| `long double` | 平台相关 | 平台相关 | 平台相关 | 需要更高浮点精度时 |

### 重要区别：范围与精度

整数类型的范围表示“能保存多大整数”。浮点类型还要看有效数字位数：

- `float` 通常约 6 到 7 位十进制有效数字。
- `double` 通常约 15 到 16 位十进制有效数字。
- `double` 能表示非常大的数量级，但不能保证这个范围内的每个整数都精确保存。

例如：

```cpp
double x = 10000000000000000.0; // 数量级很大，但相邻整数可能无法全部精确区分
```

## 不要死记平台相关的 `long`

`long` 在 Windows 和 Linux 上常见大小不同：

| 平台数据模型 | `int` | `long` | `long long` |
| --- | ---: | ---: | ---: |
| Windows 32/64 位常见 LLP64 | 32 位 | 32 位 | 64 位 |
| Linux 64 位常见 LP64 | 32 位 | 64 位 | 64 位 |

因此需要明确 64 位整数时，优先写：

```cpp
long long value;
```

或者使用位宽明确的类型：

```cpp
#include <cstdint>

std::int64_t value; // 明确要求至少 64 位有符号整数
```

## 用程序查看当前环境的真实范围

不要只根据教材或系统名称判断，可以使用 `<limits>`：

```cpp
#include <iomanip>
#include <iostream>
#include <limits>

int main() {
    std::cout << "int: "                         // 输出类型名称
              << std::numeric_limits<int>::lowest() // 输出最小值
              << " ~ "
              << std::numeric_limits<int>::max()    // 输出最大值
              << '\n';

    std::cout << "long: "
              << std::numeric_limits<long>::lowest()
              << " ~ "
              << std::numeric_limits<long>::max()
              << '\n';

    std::cout << "long long: "
              << std::numeric_limits<long long>::lowest()
              << " ~ "
              << std::numeric_limits<long long>::max()
              << '\n';

    std::cout << std::setprecision(17);         // 增加浮点输出的有效数字位数
    std::cout << "double max: "
              << std::numeric_limits<double>::max()
              << '\n';

    return 0;                                   // 程序正常结束
}
```

`std::numeric_limits<T>::max()` 查询最大可表示值；对浮点类型，`lowest()` 才表示最小的负数，`min()` 表示最小的正正规格数，二者含义不同。`<limits>` 提供了查询算术类型属性的标准接口。

## 选择规则

1. 普通整数和下标：使用 `int`。
2. 可能出现总和、乘积或路径长度超过 `2 × 10^9`：使用 `long long`。
3. 需要精确小数时，先判断浮点误差是否可接受；金额等场景不要直接依赖 `double` 的二进制精度。
4. 需要固定宽度时使用 `<cstdint>` 中的 `std::int32_t`、`std::int64_t` 等。
5. 不要因为 `long` 名字更长，就默认它一定比 `int` 大。

## 算竞中的选择

- 数据不超过约 `2 × 10^9`：通常使用 `int`。
- 可能达到 `10^9 × 10^9`、总和、乘积或路径长度：使用 `long long`。
- 题目明确给出 64 位范围：使用 `long long` 或 `int64_t`。
- 计算表达式可能溢出时，仅把结果变量改成 `long long` 还不够，参与运算的操作数也要先提升：

```cpp
int a = 100000;
int b = 100000;
long long wrong = a * b; // 先按 int 相乘，可能先溢出
long long right = 1LL * a * b;
```

## 使用规则

1. `long` 的大小依赖平台，不能只凭名称判断。
2. `long long` 常见为 64 位，标准只保证至少达到相应最低范围。
3. 用 `<limits>` 查询当前环境的真实范围。
4. 需要固定宽度时使用 `int32_t`、`int64_t` 等。
5. 防止乘法溢出时，让参与运算的操作数先转换为 `long long`。
6. 无符号类型不表示“永远更安全”，要注意下溢绕回。
