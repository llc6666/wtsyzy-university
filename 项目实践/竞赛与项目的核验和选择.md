# 竞赛与项目的核验和选择

## 结论

竞赛或项目是否值得投入，取决于规则、资源、任务和产出是否匹配，而非名称、热度或“可以加分”的传言。

## 四层核验

1. **规则层**：资格、赛道、提交物、截止时间、成员限制和评审标准。
2. **资源层**：团队、指导、设备、经费和可用时间。
3. **任务层**：要解决的问题、最低可交付版本和分工。
4. **产出层**：能否留下作品、技术资产、正式反馈或其他能力证据。

任何组织的认定规则都有版本和适用范围。它可以影响个人选择，却不能替代项目本身的价值判断。

## 一页项目卡

| 项目 | 最低要求 |
| --- | --- |
| 问题 | 能用一句话说明要解决什么 |
| 交付物 | 有可演示的最低版本 |
| 分工 | 每位成员负责什么 |
| 节奏 | 每周投入与关键节点 |
| 风险 | 技术、协作、时间与退出条件 |
| 验收 | 根据什么标准判断完成 |

## 做法

1. 先读当前官方章程，不用海报或转述替代规则。
2. 写出项目卡，核对时间和技能是否匹配。
3. 先完成最小作品，再承诺长周期目标。
4. 赛后保存最终版本、过程记录和复盘。

## 边界

被认可或获奖不等于适合所有人，也不保证长期收益。只为履历参与，常导致质量下降和时间失控。
