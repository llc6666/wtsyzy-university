# K04 控制流与循环

## 一句话结论

**分支要覆盖全部情况，循环要能终止。** 嵌入式里这两条都更严格：分支漏掉的情况会变成设备偶发失灵，循环停不下来就是死机。

## 三条容易写错的规则

### 一、多个条件可能同时成立时，不能用 `else if` 串起来

`raindrops` 就是典型：30 同时能被 3 和 5 整除，要输出 `PlingPlang`。写成 `if / else if / else if` 只会命中第一个。

正确写法是三个独立的 `if`：

```c
if (n % 3 == 0) 追加 "Pling";
if (n % 5 == 0) 追加 "Plang";
if (n % 7 == 0) 追加 "Plong";
if (一个都没命中) 输出数字本身;
```

实测（见 [嵌入式实例.md](嵌入式实例.md)）：`105 -> PlingPlangPlong`，三个条件全中。

### 二、多层例外要一层一层剥，不能只写第一条

闰年规则是「4 整除 → 100 不闰 → 400 又闰」三层。只写 `year % 4 == 0` 会把 1900 判成闰年。实测：`1900 不是闰年`、`2000 是闰年`。

### 三、无符号倒序循环不能用 `i >= 0`

`i` 是无符号数时，`i >= 0` 永远成立，减到 0 之后再减会回绕成最大值，循环停不下来。正确写法是 `i > 0`（然后在循环体里用 `i - 1`），或者干脆用有符号计数。

## 易错清单（本节）

1. 用 `else if` 处理可能同时成立的条件
2. 多层例外只写第一层
3. 无符号倒序写成 `i >= 0`
4. 循环里忘了更新计数变量 → 死循环
5. 主循环里写了阻塞等待，导致其他任务饿死
