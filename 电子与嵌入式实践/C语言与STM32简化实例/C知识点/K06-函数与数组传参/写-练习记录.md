## difference-of-squares

- 签名：`unsigned int sum_of_squares(unsigned int number)`、`square_of_sum`、`difference_of_squares`
- 题面要点：N=10 时，和的平方 3025，平方和 385，差 2640；允许查资料找更好的算法

### 验收标准（用例表 + 五类边界）

| 输入 N | 期望差值 |
| --- | --- |
| `10` | 2640 |
| `1` | 0 |
| `5` | 170 |
| `100` | 25164150 |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | `N = 0` | 0 |
| 最小 | `N = 1` | 0（1² − 1² = 0） |
| 最大 | `N = 100` 或更大 | 结果仍在 `unsigned int` 范围内（N 很大时会溢出，需要说明自己的处理） |
| 相等 | 两个相邻的 N | 差值随 N 单调增大 |
| 非法 | 无（N 为自然数） | — |

- 不变量：`square_of_sum(N) >= sum_of_squares(N)`；三个函数的结果互相一致

### 复盘三问

1. **为什么对**
2. **暴力做法为什么不行**：循环能做对，但题面鼓励找闭式公式（和 = N(N+1)/2，平方和 = N(N+1)(2N+1)/6）；比较两种做法的数值上界
3. **哪里最容易错**：`i <= number` 写成 `i < number`；中间结果溢出

## darts

- 题面要点：外圈半径 10（1 分）、中圈 5（5 分）、内圈 1（10 分）、外面 0 分；圆心在 (0,0)
- 需要 `<math.h>`，链接时加 `-lm`

### 验收标准（用例表 + 五类边界）

| 坐标 (x, y) | 期望 |
| --- | --- |
| `(0, 0)` | 10 |
| `(0, 10)` | 1 |
| `(0, 10.1)` | 0 |
| `(-5, 0)` | 5 |
| `(6, 6)` | 1（距离约 8.49，在外圈内） |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | 无输入（不适用） | — |
| 最小 | `(0, 0)` | 10 |
| 最大 | 很大的坐标 | 0，且不溢出（`x*x` 可能溢出，先转 double） |
| 相等 | 距离正好等于 1 / 5 / 10 | 按题意确定边界归属，建议统一算作命中内圈 |
| 非法 | 负坐标 | 与正坐标对称处理（用平方，不要开方后判符号） |

- 不变量：得分只取决于到圆心的距离；距离越大得分不增

### 复盘三问

1. **为什么对**
2. **暴力做法为什么不行**：可以直接比较距离平方与各半径平方，省掉 `sqrt`；比较两种做法
3. **哪里最容易错**：边界用 `==` 判浮点；`x*x` 用 `float` 时大数溢出

## triangle

- 接口：`triangle_t` 结构体 + `is_equilateral` / `is_isosceles` / `is_scalene`
- 题面要点：边长 > 0 且满足三角不等式；等腰按「至少两条相等」，所以**等边也是等腰**

### 验收标准（用例表 + 五类边界）

| 三边 | 期望 |
| --- | --- |
| `(2,2,2)` | 等边（同时也是等腰） |
| `(3,4,4)` | 等腰 |
| `(3,4,5)` | 不等边 |
| `(1,1,2)` | 退化，本题不测（按自己约定处理） |

| 类型 | 用例 | 期望 |
| --- | --- | --- |
| 空 | 边长为 0 | 不是三角形 |
| 最小 | 很小的正边长（0.001） | 正常判定 |
| 最大 | 很大的边长 | 加法不溢出 |
| 相等 | 三边相等 | 同时满足等边与等腰 |
| 非法 | 边长为负或 0，或 `(1,2,3)` | 不是三角形，三个判断都返回 false |

- 不变量：非法三角形时三个函数全为 false；等边 ⇒ 等腰；不等边与等腰互斥

### 复盘三问

1. **为什么对**
2. **暴力做法为什么不行**
3. **哪里最容易错**：把「等边」排除在「等腰」之外；浮点相等用 `==`
