# 冒泡排序：相邻交换与提前结束

## 什么时候用

仅用于理解相邻元素交换和“提前结束”优化，或调试极小数据。真实的数组和 `vector` 排序应优先使用 `std::sort`。

## 机制

每次从左到右比较相邻的 `a[i]` 与 `a[i+1]`。左边更大就交换，于是这一轮的最大值被一步步推到当前未排序区间末端。若一整轮没有任何交换，数组已经有序，可以提前退出。

只在 `>` 时交换，值相等的元素不会互换位置，所以它稳定。

## 最小可运行示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

void bubble_sort(std::vector<int>& a) {
    for (int end = static_cast<int>(a.size()) - 1; end > 0; --end) {
        bool changed = false;
        for (int i = 0; i < end; ++i) {
            if (a[i] > a[i + 1]) {
                std::swap(a[i], a[i + 1]);
                changed = true;
            }
        }
        if (!changed) break;
    }
}

int main() {
    std::vector<int> a = {5, 1, 4, 2, 8};
    bubble_sort(a);
    for (int x : a) std::cout << x << ' ';
}
```

预期输出：

```text
1 2 4 5 8
```

## 如何验证

把输入改成 `{1, 2, 3, 4, 5}`，在 `if (!changed)` 前输出 `end`，你会看到第一轮就退出。把 `>` 改为 `>=`，数值仍可能有序，但相等元素会交换，稳定性消失。

## 复杂度与边界

- 已排序输入配合提前结束为 `O(n)`；平均和最坏为 `O(n^2)`。
- 额外空间 `O(1)`，原地且稳定。
- 不适合大数据；“容易写”不是选择它处理真实大数组的理由。
