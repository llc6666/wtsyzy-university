# Linux 快通与 OpenWrt 六册入门

会用终端的第一步，是知道自己**在哪台机器、以什么身份、要看哪一层**。先在本地练文件和脚本，再到自己管理的 OpenWrt 设备上读运行状态。用不到设备时，网络和无线两册可以先读示意输出。

## 快通：按手上的问题查

| 现在卡在哪 | 先做什么 | 下一步 |
| --- | --- | --- |
| 第一次进终端，不确定进了哪个系统 | 用 `id`、`pwd`、`cat /etc/os-release` 核对身份、目录和发行版 | [第一册](第一册-系统与终端.md) |
| 教程里的命令没有或参数无效 | 用 `command -v` 查命令，用设备实际支持的帮助查选项 | [第一册](第一册-系统与终端.md) |
| 要修改一个配置值 | 先保存原件，改副本并对比差异；在设备上把暂存、持久化、应用和恢复分开 | [第二册](第二册-文件与文本.md)、[第三册](第三册-进程权限与服务.md) |
| 服务没起来，或者改完没有生效 | 分开查进程、监听、近期系统日志和内核日志，先记录再决定是否重启 | [第三册](第三册-进程权限与服务.md) |
| 能连设备但访问不到服务 | 依次核对接口地址、选路、邻居、名称解析和目标服务 | [第四册](第四册-网络配置与排错.md) |
| 每次都手抄日志统计 | 先约定输入和退出码，再把命令写成可移植的 `sh` 脚本 | [第五册](第五册-Shell脚本.md) |
| 要判断网卡支持什么、现有 mesh 有没有邻居 | 对照 `iw list`、`iw dev`、对端状态和 mesh 路径表 | [第六册](第六册-无线与Mesh状态.md) |

如果准备在 MT7621 一类的路由器上练习，先记下**整机型号、硬件修订版、当前系统版本和恢复入口**。SoC 型号只能帮助缩小范围，同一 SoC 可以用于不同板型。软件包、接口命名和系统管理命令以设备实际镜像为准。开始阶段只读即可，不需要升级固件。

## 动手前先确定恢复方式

涉及真实设备时，练习顺序是**记录当前状态 → 在副本里改一项 → 确认可以恢复 → 按服务文档应用 → 比较结果**。备份放到设备重启后仍可取得的位置；只有 SSH 一条路时，先不要变更它依赖的 IP、接口或登录服务。固件升级、恢复出厂、串口接线按整机型号、修订版和厂商资料另行确认，本专题不提供一套通用的刷机命令。版本可从 [OpenWrt 官方发布页](https://github.com/openwrt/openwrt/releases)查起。
