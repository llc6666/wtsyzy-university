# PPTmaker：可复用演示文稿工作流

这是一个面向课程汇报、答辩、竞赛、社团项目和求职展示的公开版 PPT 工作流。它把选题、叙事、素材授权、制作和验收拆成可执行步骤。

入口：[PPT-资源库/README.md](PPT-资源库/README.md)。

## 公开版包含什么

- 可直接照做的制作规范和交付验收清单。
- 素材许可证登记表、单项目素材使用记录模板。
- 图标、插画、照片、字体、模板和图表的官方来源与使用边界。
- 图标索引和资源库核验脚本，供拥有本地素材包时使用。

## 有意不随仓库分发什么

- 具体课程、学校、社团、客户或求职项目的课件源文件和导出稿。
- 个人信息、账号配置、内部路径和未公开资料。
- 约 108 MB 的第三方图标与表情资源包。它们的版本、官方来源和许可证已登记，使用时请从官方项目获取并保留对应许可证。
- 来源不明的商业模板、字体、照片、论文配图和 Logo 合集。

## 使用顺序

1. 用一句话写出听众要带走的结论。
2. 列出支撑结论的 3 至 5 个证据，并标明来源。
3. 先画低保真页面结构，再选图标、图片和模板。
4. 将每个外来素材写入项目自己的素材使用记录。
5. 导出 PDF，在 100% 和全屏投影场景下验收。
6. 交付源文件、PDF、素材记录和演讲备注。

| 目录 | 作用 |
