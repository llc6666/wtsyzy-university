# 题面：环形缓冲

> 来源：exercism/c 仓库 `exercises/practice/circular-buffer`（MIT 许可）。本文为中文译写，英文原件未保留。

环形缓冲（也叫循环缓冲、ring buffer）是一种数据结构：用一块**固定大小**的缓冲，把它当成首尾相连来用。

初始状态是空的，长度预先定好。例如这是一个 7 元素的缓冲：

```text
[ ][ ][ ][ ][ ][ ][ ]
```

假设往中间写入 1（从哪个位置开始不重要）：

```text
[ ][ ][ ][1][ ][ ][ ]
```

再追加两个元素 2 和 3：

```text
[ ][ ][ ][1][2][3][ ]
```

如果取出两个元素，被取走的是缓冲里**最旧**的值，也就是 1 和 2，剩下 3：

```text
[ ][ ][ ][ ][ ][3][ ]
```

当 7 个元素都写满时，缓冲就是满的：

```text
[5][6][7][8][9][3][4]
```

**缓冲满的时候写入会报错**，告诉调用方：在腾出空位之前不能再写。

调用方也可以选择**强制写入**，用新数据覆盖最旧的数据。例如再写入 A 和 B，覆盖掉 3 和 4：

```text
[5][6][7][8][9][A][B]
```

此时 5 变成最旧的数据。如果再取出两个元素，会得到 5 和 6：

```text
[ ][ ][7][8][9][A][B]
```

这时有空位了，如果再强制写入 C 和 D，用的是刚才 5 和 6 腾出来的位置，而不是 7 和 8 的位置。7 仍然是最旧的元素，缓冲再次变满：

```text
[C][D][7][8][9][A][B]
```

## 需要自己定的三件事

头文件是空的，接口由你设计。设计前先回答：

1. 缓冲满时写入是报错还是覆盖？（题面要求：普通写入报错，另提供强制写覆盖）
2. 满和空怎么区分？（`head == tail` 时分不清，要么留一个空位，要么额外记一个计数）
3. 读空缓冲时怎么表示失败
